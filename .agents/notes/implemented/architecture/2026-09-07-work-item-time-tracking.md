# Agent Note: 工作项原始计时、单人单计时与跨端退出语义

Status: implemented

## Problem

表格、浏览器标签页和桌面小窗口需要操作同一计时事实。把秒表状态放在页面、关闭页面即停止，或把子项时长重复加到父项，会使多设备工时不一致。未来 Worklog 的填报与审批也需要原始来源，不能反向改写计时事实。

## Decision

原始会话归属 workitem。V51 保存 UTC 起止时间、独立会话版本、用户计时状态版本和项目计时修订号；公司与用户组成互斥范围，用户状态行锁与活动会话唯一索引共同保证单人单计时。切换在同一幂等事务中停止原会话并创建新会话。秒表跳动只发生在客户端，不推进工作项字段版本。

单元格展示全员累计，父项与子项分别累计。时长追踪日志使用单元格下方的固定尺寸弹层，按服务端游标滚动追加记录。清除沿用既有逐条删除 API，遍历所有分页但仅处理本人有编辑权限的已停止记录，要求原因并保留审计；发生部分失败时报告已完成数量，不宣称批量原子性，也不扩大删除权限。本人只能修正本人已停止记录；编辑无需填写修正原因，删除仍须提供原因，两者均进入审计。历史删除保留墓碑；起止交叠按用户跨项目检查。项目生命周期共享锁在用户状态锁之前取得；项目计时修订行按 UUID 排序更新。停止既有会话不依赖当前项目写权限；不可见项目只返回停止所需的最小状态。

时长排序和范围过滤先在 SQL 完成，再执行游标分页。计时游标固定取值时点并包含修订号；启停和修正使旧计时游标失效，客户端重新加载，秒数增长不触发每秒重排。最近计时项从服务端会话事实读取并按当前项目可见性过滤。应用级状态每五秒批量校准，使用 BroadcastChannel 和受控 IPC 通知跨窗口刷新。

计时在关闭页面、退出应用、断网和休眠后持续，直到主动停止。Web 原生关闭提示只提供浏览器允许的离开/留下语义；应用内登出与桌面退出提供停止并退出、继续计时并退出、取消。停止失败保留应用；桌面主进程通过带请求标识的握手去重退出，收到 renderer 的服务器确认结果后才退出。

桌面小窗口复用认证 session partition，保持 sandbox、contextIsolation 和关闭 Node integration。它进入项目时默认置顶、不抢焦点，主动从工具栏打开时恢复并聚焦，关闭只隐藏，同项目路由切换不重新弹出；只有登记的主窗口与计时窗口主 frame 可以调用固定白名单通道。Web 在用户操作中尝试 Document Picture-in-Picture，再使用同源普通弹窗，并保留页内入口；浏览器能力不等同于桌面置顶保证。

`TimeTrackingRecordQuery` 是面向后续 Worklog 的 actor-scoped 分页只读端口，不公开计时写入口。本决策补充 [M3 公开端口约定](2026-08-31-m2-exit-and-m3-public-ports.md)，不改变已有 Project/Product 锁序、审批 blocker 的归属或部署完成定义。

计时日志的添加和编辑采用分钟输入；已编辑记录通过持久化 rowVersion 与来源识别（手动记录大于 0、自动计时停止后大于 1），日期与起止时间标为 `#D83A52`。工作项详情动态仅订阅计时修改 v2，保存修改前后 UTC 时间范围及会话引用，前端按公司时区显示；无变化的起止范围不产生动态，不订阅启停、补录及删除。修改 v1 保留冻结，新 v2 增加类别定位和原时间快照，避免从当前事实猜测历史。

## Alternatives considered

- 使用 localStorage 保存独立计时事实：无法约束多设备并发，也无法可靠审计，因此只使用服务端会话事实。
- 每秒更新数据库或工作项版本：造成无意义写入、字段版本冲突与排序抖动，拒绝。
- 在 unload 中请求自动停止：浏览器无法保证请求送达，且崩溃与主动关闭表现不一致，拒绝。
- 父项自动汇总子项计时：会在跨层级导出时重复累计；原始记录分别归属，汇总由后续报表明确选择。
- Worklog 直接查询或修改 workitem 内部表：绕过授权和原始事实职责，沿用公开端口约定。

## Consequences

发布顺序是数据库/后端、Web、桌面。旧客户端不识别计时摘要仍可读取工作项；旧幂等响应可以省略新摘要。回滚 UI 不删除计时表和审计记录。当前变更不包含工时导出、周填报、审批或生产部署；代码落地和本地测试不代表 PR 已合并。

自动化验证覆盖事务幂等、多人累计、历史修正、长时记录、计时分页、窗口隔离和退出握手。原生桌面交互及浏览器画中画的实际能力仍需与所运行的宿主环境共同验收，不能以模拟 IPC 测试代替真实窗口行为。

## Verification

本地 PostgreSQL HTTP 集成测试覆盖并发启停、历史修正、跨项目切换和撤权停止，包含独立设备同时启动与撤权后的停止；Web 全量 307 项、桌面单元 27 项、SDK 14 项通过。另有 Web 画中画成功、拒绝及弹窗拦截三项能力分支测试。真实 Electron 验收覆盖自动小窗口、隐藏重开、主窗口最小化后启停、取消退出、停止失败、停止并退出与继续计时并退出，两次验收的记录均已清理并留下审计。

OpenAPI 的两条排序正则仅扩大枚举选择集合，保留全部旧值。openapi-diff 无法证明正则包含关系并报告不兼容；将这两条正则恢复为旧表达式的临时副本已通过完整比较；计时动态新增 TIME_TRACKING 枚举后的当前规范也已重新通过同一比较，两条精确映射同步绑定新规范哈希，未增加兼容性豁免范围。`breaking-change-exceptions.json` 按 dev 与当前规范的精确 SHA-256 放行这一次误报；另保留类别重构验收要求的原始历史基线到当前规范的精确映射，继承已记录的类别与评论例外，不放宽其他版本或其他变化。旧事件冻结清单的 14 个版本与 dev 基线比较通过。
