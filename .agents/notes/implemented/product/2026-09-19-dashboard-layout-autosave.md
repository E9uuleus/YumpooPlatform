# Agent Note: 仪表板自动避让与窗口独立保存

Status: implemented

## Problem

组件高度跨断点共享，但拖动、缩放只写当前断点的位置，使另一断点的高度增大后发生重叠并被服务端拒绝。原先的 412 冲突恢复要求用户选择副本或丢弃，不符合每个窗口持续编辑自身布局、刷新才切换到最新保存结果的产品要求。

## Decision

本记录部分替代[保存恢复与展开视图](2026-09-18-dashboard-recovery-and-exploration.md)的人工版本冲突处理，以及[自定义图表](2026-09-17-dashboard-custom-charts.md)的常驻保存状态提示。[私人仪表板](2026-09-16-personal-dashboards.md)的所有权、权限交集和强 ETag 契约，以及[固定组件高度](2026-09-18-dashboard-stable-widget-height.md)的跨断点高度规则继续有效。旧记录仍拥有展开视图、异常恢复、统计及图表配置决策，不做整体归档。

[DashboardGrid](../../../../frontend/web-app/src/components/dashboard/DashboardGrid.vue) 手势结束读取当前列数的完整布局，包含被推开的组件。共享高度写入 wide 与 medium 后，[dashboardLayout](../../../../frontend/web-app/src/components/dashboard/dashboardLayout.ts) 保持横向位置与宽度并消除两个断点的重叠。拖动碰撞及何时收拢空隙由[拖拽目标位置优先](2026-09-20-dashboard-drag-destination.md)部分替代：拖动、加载和普通配置编辑保留有效落点及空隙，缩放结束与删除仍显式收拢。仅视口变化不保存。

拖动或缩放结束立即串行保存；设置输入沿用 650ms 防抖。主页面与组件设置不展示正在保存、已保存或未保存状态图标。真实网络、权限和配置错误仍保留草稿、错误原因与重试入口，避免将保存失败伪装为成功。

[useDashboard](../../../../frontend/web-app/src/components/dashboard/useDashboard.ts) 遇到 412 时读取最新版本号，仅更新 ETag，不把远端配置应用到当前画面；新幂等键提交本窗口最新的完整配置。连续竞争最多立即重试三次，随后让出 650ms 自动再试。网络结果不确定仍保留原请求体、ETag 和幂等键，不能将不确定写入误当作明确拒绝。

服务端最终保存最后一个成功请求的完整配置，不做字段级合并，也不广播配置覆盖已打开的窗口。新打开的 Web 或客户端读取服务端最新配置；既有窗口仅在显式刷新或重新进入时整体载入。请求中的修改继续保留，过期响应不得覆盖新编辑或另一个仪表板。

## Alternatives considered

- 禁用后端重叠校验：会容许损坏布局持久化，也不能解决画布空隙，因此保留校验并修复两个断点。
- 修改服务端为无条件覆盖：会扩大 API 契约变化并削弱其他调用者的版本检查；客户端按明确产品意图重取 ETag 即可。
- 跨窗口实时广播布局：会打断当前窗口的编辑，不符合刷新前保持自身布局的要求。
- 自动合并不同窗口的组件或字段：无法表达删除、排序和整体布局的优先级，用户要求的是各窗口完整修改的保存顺序。

## Consequences

较晚保存的窗口可能覆盖另一窗口刚保存的配置，这是本次明确采用的产品行为。没有数据库迁移、接口字段或依赖变化。几何收拢不改变控件横向位置来填满任意空洞，保留用户选择的列和顺序。持续高频竞争会暂缓保存，但不会把其他窗口的布局加载到当前画面。

## Verification

仪表板 45 项测试通过，覆盖两种列数的真实网格移动、放大、缩小及重载，另一断点高度同步、旧版本重试、重取版本时继续编辑、跨仪表板过期响应和持续竞争让步。全量前端 59 个测试文件、511 项用例通过；类型检查、生产构建、改动文件 lint 与文档校验通过。Computer Use 在本地 Web 实测六列/十二列缩放、碰撞避让、缩小跟进、两窗口分别保持 12/8 行布局，以及显式刷新和页面重载后读取最新保存值；正常操作无保存状态提示和重叠错误。测试尺寸与位置已恢复，临时浏览器页面和视口覆盖已清理；原生桌面窗口未单独进行交互验收。
