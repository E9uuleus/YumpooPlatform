# Agent Note: 连接列的表格体验与隔离边界

Status: implemented

## Problem

跨项目协作需要在工作项表格里直接看到对端工作项，并允许来源项目成员向其他项目提交工作项。连接是独立于既有工作项关系的聚合，不能套用关系的占位隐藏行为，也不能让连接卡片成为绕过目标项目权限的编辑入口。

既有内置列偏好跨项目共享，用户命名的连接列则只属于当前项目。混合存储、按显示名称寻找列或把连接列参与内置列排序，都会使项目切换、重名与列宽变更互相污染。

## Decision

- 表头和分组、子项表的「+」共用列中心，仅包含已实现的「连接项目」类型与恢复隐藏列入口。列目录的 `canManage`、`canDelete` 决定管理入口，归档及公司管理员只读状态关闭写入口。
- 连接列按服务端顺序固定在内置可移动列之后，被连接列始终最后；连接列不参与拖拽、筛选、排序或分组。所有宽度和显隐使用 `connect:<columnId>`、`connect-incoming` 键，不依赖列名称。
- 连接列偏好单独保存在 `yumpoo:project-work-items:connect:v1:{companyId}:{userId}:{projectId}`。损坏值和已失效列键被忽略，宽度有默认值与下限；拖动时实时显示列宽，松手后保存，取消拖动恢复原宽度。内置列存储保持独立。
- 主表与子项表共用连接上下文和组件。单元格按最多 100 个工作项一批加载、缓存和刷新；项目或身份变化中止读取并丢弃旧响应，刷新修订号避免慢响应覆盖新结果。列操作只刷新目录并清理失效列缓存，连接写操作由数据层刷新受影响行，界面不重复刷新；手动重试包含已加载子项。仪表板嵌入模式不渲染连接列，也不请求连接目录或单元格。
- 单元格中只呈现服务端提供的连接卡片投影。成员可以搜索并关联已有工作项；`actorCanLinkExisting=false` 时不请求候选，但允许使用新建并关联入口。卡片字段只读，`canOpen` 决定项目与工作项跳转，`canUnlink` 决定解除连接；服务端仍是写权限的最终依据。
- 设置页的连接概览同时使用目录 `items` 和 `incomingColumns`，管理链接回到当前项目表格并恢复、定位对应列；定位成功后移除 `connectColumn` 查询参数，后续隐藏与刷新遵守个人偏好。被连接单元格按来源项目和列分组，超出首批的连接在用户展开后分页加载。只读空单元格保持空白，不提供弹窗入口。

实现入口为 [连接数据层](../../../../frontend/web-app/src/components/projects/connect/useConnectColumns.ts)、[表格集成](../../../../frontend/web-app/src/components/projects/connect/useConnectTable.ts) 和 [视觉验收区](../../../../frontend/web-app/src/visual-acceptance/ConnectColumnsPreview.vue)。权限与投影边界沿用 [连接接收与卡片可见性](../security/2026-09-30-connection-intake-and-card-visibility.md)。

## Alternatives considered

- 把连接列与内置列混排、共用偏好：跨项目共享偏好无法表达项目私有列，且重名会误改内置列，因此使用独立键与固定区域。
- 在列中心预告更多列类型：不可操作的入口会造成错误期待，当前只呈现真实能力。
- 对非目标成员完全隐藏目标卡片，或开放整张工作项详情：前者阻断接收与协作反馈，后者扩大信息暴露。沿用服务端最小卡片投影，并通过 `canOpen` 控制详情访问。
- 在卡片里直接编辑对端字段，或给仪表板加入跨项目连接列：都会扩大本批次的权限与共享表格复杂度，当前保留只读卡片和项目表格边界。
- 逐行查询连接：根表、分组与子项展开会产生大量请求，因此以工作项 ID 批次、缓存和过期响应保护统一处理。

## Consequences

连接标签、单元格弹窗、创建、列管理与卡片形成同一套可复用组件，主表只负责集成。按 key 的查找和项目、身份隔离避免跨项目偏好污染；单元格可通过批量刷新跟随创建、删除、恢复及连接写操作变化。

现有目录与批量单元格接口没有全列连接总数，删除确认保守说明「解除该列全部连接」，删除成功后显示服务端实际 `removedConnectionCount`。不以当前加载的页面计数冒充全列总数，不扩展接口字段；PR 评审已接受此文案，设计包文字留待整体交付后同步。

视觉验收区使用静态数据驱动正式组件，覆盖三种身份、单/多目标、溢出、空态、被连接与缺省/归档卡片；它用于界面核对，不代表生产数据或后端部署状态。连接筛选、看板展示与目标负责人通知属于后续独立交付。
