# Agent Note: 工作项表格个人设置

Status: implemented

## Problem

项目工作项表格需要 Monday 式的固定列、表头与行高、条件着色和新建默认值。这些设置属于个人的展示与录入习惯，需要随账号跨设备生效；条件和默认值又引用项目自己的成员、标签与类别，必须按项目隔离。现有偏好分三类，都存在本机：内置列的顺序、宽度、隐藏与折叠跨项目共享；连接列偏好按项目隔离；分组偏好按账户、企业和项目隔离。

## Decision

workitem 模块提供 `GET/PUT /me/projects/{projectId}/work-item-table-settings`（[契约](../../../../contracts/openapi/yumpoo-v1.yaml)），由 `work_item_table_settings`（V67）按 Company、Project、User 保存一个 jsonb，只对 company 建外键。只要项目对当前账号可见，就能读写自己的设置。PUT 整体替换，只要求会话与 XSRF。服务端只校验结构与上限，不校验引用是否仍有效：固定列不超过 50，规则不超过 20 条，每条值不超过 20 个且每个不超过 100 字，默认处理人不超过 20 人，截止日期偏移 0–365 天。离开的成员、停用的标签与类别由 Web 在使用时静默忽略。内置列的顺序、宽度、隐藏与折叠仍按原决策存在本机，不迁移。

[Web 菜单](../../../../frontend/web-app/src/components/projects/WorkItemTableSettingsMenu.vue)位于工具栏"小计时器"右侧。修改即时生效，停顿 400ms 后按调用顺序串行保存；读取失败时菜单只提供重试，不会用默认值覆盖服务端。

固定列采用冻结前 N 列语义，只保存工作项名称列之后冻结的列数。实现上按当前可见列顺序取前 N 列绑定 ElTable 的 `fixed`：内置列在前、连接列在后，隐藏列与新建连接列草稿不计入。拖拽列顺序不改变 N。固定区宽度超过"表格可视宽度 − 前导列 − 200px"时，不能再勾选更多列。固定列面板打开时拖动列头不会关闭菜单。

表头与行高各分三档：表头 38/56/76px，行 36/56/76px。只放大真实工作项行与表头；双行、三行时，名称和列名分别最多显示 2 行、3 行。分组标题、添加行与子项表保持原高度。

每条条件着色规则由颜色、作用范围（单元格或整行）、列、运算符与值组成。行与每个单元格分别取列表中第一条命中的完整规则；未填完整的规则会保存，但不生效。可选的列限于工作项名称、处理人、状态、优先级、类别与截止日期；其中状态、优先级、类别是色块单元格，只能作用于整行。日期按企业时区比较，"已过去"只表达日期关系。背景为标签色以 32% 混入表面色，保持不透明，以适配固定列；选中行高亮优先于条件色。

新建默认值包含处理人、状态、优先级、类别与截止日期（创建当天或之后 N 天，按企业时区）。默认值只作用于主表的底部添加、在下方插入与分组末尾添加，分组字段的值优先；子项与复制不套用。新建接口不接受状态，默认状态在创建成功后迁移。分组添加沿用分组新增的"失败只重试迁移"；其余入口在迁移失败或用户跳过迁移说明时只提示，不回滚创建。为支持项目自定义优先级，根项新建请求的优先级校验改为与服务层的代码格式一致。

## Alternatives considered

- **只存本机：** 实现最轻，但配置条件与默认值成本高，换设备或浏览器就会丢失。经讨论改为服务端个人设置。
- **默认值作为项目共享设置：** 更接近 Monday 看板级默认值，但需要负责人治理与覆盖规则；当前把它定位为个人录入习惯。
- **按列名固定：** 固定列始终排在最左且不能拖出，与拖拽排序冲突。冻结前 N 列与 Excel 一致，也与列顺序天然兼容。
- **子项表同步应用：** 子项表有独立的列顺序与固定方式，本次只覆盖主表。
- **后端校验引用：** 成员离开或标签停用后，已保存的设置将整体无法更新。改为使用时忽略失效值。

## Consequences

项目或成员被移除时，设置不会自动删除，重新可见后沿用原设置。内置列顺序仍是本机偏好，因此具体被冻结的列会随本机列顺序变化，这是冻结前 N 列语义的预期结果。后续如果要支持连接列默认值、更多条件列或子项表，应扩展本设置结构，不得新增第二份个人表格设置。测试覆盖如下：`WorkItemHttpIT` 验证默认值、整体替换、校验与不可见项目返回 404；`workItemTableSettings.spec.ts` 与 `useWorkItemGroupCreate.spec.ts` 验证着色优先级、默认值解析与分组字段优先。
