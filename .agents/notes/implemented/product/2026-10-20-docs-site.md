# Agent Note: 文档中心 /docs

Status: implemented

## Problem

应用内没有任何帮助入口，用户文档只有面向管理员的桌面安装与隐私说明。[新手引导](2026-10-11-new-user-onboarding.md)只讲当前界面，概念、规则与口径（例如并行计时如何计入、加班如何统计）无处可查；开发者了解架构只能读散落的 README 与 Agent Note。需要一个与应用同版本发布、登录故障时也能打开的文档中心。

## Decision

- **形态：** 文档中心是 web-app 的公开路由 `/docs`（`meta.public`，与 `/download` 相同），随 Web 构建进入发布包，不改 nginx、部署引擎或发布流程。源文件是 `frontend/web-app/src/docs-site/content/` 下的 Markdown、手写 SVG 架构图与精选 PNG 实操截图。Vite 插件 `build/docs/markdown.ts` 在**构建期**编译，同一个 `.md` 按 query 产出三种模块：`?meta`（导航与目录，布局 eager 导入）、`?search`（纯文本搜索索引，首次搜索时懒加载）和正文 HTML（按页懒加载）。运行时不引入 Markdown 解析器。
- **安全：** 生产 CSP 为 `default-src 'self'`，插件只输出 class，最终 HTML 出现 `style=`、`<script` 或事件属性即构建失败；架构图经 Vite 内置 `?raw` 读入后同样校验，并以内联 SVG 渲染（`.svg` 会先被资源插件加载为 URL，`?raw` 是拿到原文的最小方式）。`vite preview` 携带与线上相同的 CSP 头，本地冒烟因此兼作 CSP 回归检查。文档全部匿名可读，内容不写生产主机名、服务器目录、服务账号、计划任务名、端口映射或密钥，运维 Runbook 仍只留在仓库。
- **内容：** 分为介绍、快速开始、使用指南（帮助中心）和架构四个分区。概念、规则与口径以文字为主，快速开始允许精选实操截图，弥补新用户不易将文字与操作位置对应的问题。截图只用演示数据与统一浅色主题，裁切到操作区域并紧邻对应步骤；每张图必须有替代文本和“操作位置＋预期结果”图注。界面改变时同步重拍相关截图，不把整套界面复制为图片手册。PNG 保存在受版本管理的 `content/screenshots/`，构建器校验路径和 PNG 尺寸，以 Vite `?no-inline` 打包为同源文件，输出固有宽高与懒加载，避免 data URL 违反 CSP 以及加载后布局位移。界面名称用「」并与界面文字逐字一致。
- **切页：** 异步加载期间保留上一页快照，新正文就绪后原子替换标题、目录、正文与前后篇，再定位一次顶部或锚点；过期请求不得覆盖当前页，失败保留内容并提供重试。文档路由预留滚动条空间。
- **防漂移：** `docsContent.spec.ts` 校验 front matter、站内链接与锚点、`appRoute`、`tour`、路由帮助映射覆盖 AppShell 下全部页面；文档引用的仓库文件渲染为路径，同时由 `pnpm doc-sync` 校验目标存在，文件移动时 CI 失败。
- **入口：** 顶栏「帮助」菜单（本页帮助、快速开始、帮助中心、常见问题），本页帮助按 `routeHelp.ts` 的路由映射定位到小节；登录页、下载页、欢迎弹窗也有入口。浏览器中新开标签页；桌面壳拒绝 `window.open`，在同一窗口打开，文档顶栏「进入工作台」返回。
- **顶栏随之改为图标按钮组：** 依次为「查看本页引导」「帮助」「收件箱」「偏好设置」，分隔线后是头像菜单。外观切换器移出顶栏，外观设置只在偏好设置页；“查看本页引导”从头像菜单移到独立按钮，当前页面没有导览时禁用；不再显示“Web 浏览器 / Electron 在线壳”客户端标签。

## Alternatives considered

- 独立 VitePress 站点：生成的页面依赖内联脚本，违反 CSP；主题与应用的 `yp` 设计系统分裂。
- 独立静态目录加 nginx location：每次部署都要人工改主机配置，且与现有 SPA 回落规则冲突。
- 登录后才可读：登录故障恰恰是最需要帮助的时候，帮助会不可达。
- 运行时渲染 Markdown：运行时包体积增加，渲染内容无法在构建期做安全检查。
- 顶栏保留外观切换器并新增帮助：顶栏按钮过多，外观属于低频设置，已有偏好设置页承载。

## Consequences

用户可见的界面、流程或架构改动需要在同一 PR 同步更新文档页面与导览。文档内容增加 Web 构建产物，但按页拆分、懒加载；搜索是客户端子串匹配，适合当前几十页的规模，页数显著增长时需要重新评估。帮助菜单只覆盖 AppShell 下的页面，壳专用页面（`/timer/*`）不提供本页帮助。外观仍按设备保存，用户需要进入偏好设置页切换主题。

## Verification

`build/docs/markdown.spec.ts` 覆盖锚点算法与 doc-sync 一致、四类链接改写、容器、代码块转义与 CSP 违规时构建失败；`docsContent.spec.ts` 覆盖全部页面的内容防漂移；`DocsPage.spec.ts`、`DocsSearch.spec.ts`、`docsRoutes.spec.ts` 覆盖渲染、锚点滚动、站内链接、复制、搜索排序与键盘操作、匿名访问；`App.spec.ts` 覆盖顶栏按钮。本地冒烟增加「文档中心」用例。
