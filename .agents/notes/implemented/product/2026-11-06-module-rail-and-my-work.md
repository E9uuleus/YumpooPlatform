# Agent Note: 模块栏个人入口与我的工作

Status: implemented

## Problem

工作台二级菜单同时承载仪表板、我的工时、当前项目和项目列表。再加入跨项目的「我的工作」会拉长菜单，也让个人入口更难找到。

## Decision

首页、工作台、仪表板和我的工时依次显示在模块栏，之后按既有角色权限显示团队、公司管理与运维。仪表板与我的工时各有独立的 `shellSection`，由 `CONTEXTLESS_SECTIONS` 统一控制二级导航。工作台二级菜单只保留当前项目与项目列表。仪表板、我的工时和我的一天沿用原 URL，桌面快捷小窗仍可跳转到对应日期。

## Alternatives considered

保留全部个人入口会进一步拉长项目导航。工作台仍保留原名，沿用成员熟悉的入口。

## Consequences

矮视口收紧模块栏项高与间距，容纳不下时可在模块栏内滚动。

## Verification

外壳和路由测试覆盖成员模块栏顺序、项目导航、仪表板与工时页面的活动分区。
