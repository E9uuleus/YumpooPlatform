# Agent Note: 模块固定页框与统一页头

Status: implemented

## Problem

运维中心、公司管理和偏好设置的页面由文档滚动，模块栏、二级导航和标题随内容离开视口。仪表板、我的工时和团队通过 AppShell 中的路由名白名单锁定视口，新增固定页面需要修改外壳。团队、公司管理和运维的标题层级也不一致，公司管理各子页只显示同一个模块标题。

未声明 fixed 的页面（管理项目、归档项目、项目统计/成员/动态/设置、首页、收件箱）仍由文档滚动，工作台菜单随内容滚走。

## Decision

- 桌面宽度（≥960px）下外壳始终锁定为视口高度，正文在 `.app-main` 内滚动并保留其内边距；路由 `meta.frame: 'fixed'` 只表示页面自管滚动区（`.app-main` 无内边距、不滚动），取代按路由名硬编码的白名单。移动宽度下非 fixed 页面仍由文档滚动。（2026-10-31 起；此前 fixed 是视口锁的唯一来源。）
- 模块页使用 `YpModulePage`，页头固定、正文独立滚动；使用 `YpModuleHeader` 统一方案 D：40px 模块色图标、模块名、24px/600 标题、操作靠右、无描述。公司管理标题随当前子页切换。
- 团队保留自己的工具栏和内部滚动区，只替换页头。
- `YpPageHeader` 只留给收件箱。

## Alternatives considered

- A：完整沿用「管理项目」页头，约 140px 高，固定后内容区损失过大。
- B：56px 紧凑栏，层级弱，无法区分模块。
- C：28px 标准页头，无图标识别，也比 D 高。
- 继续扩充路由名白名单：每新增一个页面都要修改 AppShell，页面的布局需求无法由路由自行声明。
- 给管理项目、归档项目逐个声明 `frame: 'fixed'` 并改用 `YpModulePage`：要重做目录页顶部渐变带与页头，且其余未声明的页面仍会带着菜单滚动。
- 只锁定工作台区域：首页、收件箱等仍是另一套滚动模型，规则分叉。

## Consequences

- 新增模块页只需在路由上声明 `frame: 'fixed'` 并使用 `YpModulePage`。
- 运维和公司管理的内容边距从 40px 改为 24px，与仪表板一致。
- 页头与正文滚动职责分离；仪表板、我的工时和团队继续使用原来的内部滚动布局。
- 所有页面在桌面宽度下内容区滚动；sticky 元素以 `.app-main` 为参照；切换路由时 `.app-main` 的滚动位置与此前文档滚动一样不自动复位。
