# Agent Note: 项目连接筛选与增强入口

Status: implemented

## Problem

连接列已经能够跨项目展示最小卡片，但表格只加载当前页，不能用当前页连接缓存准确筛选项目工作项。连接过滤若在分页后执行，会产生稀疏页面、错误计数及游标串用。

## Decision

项目列表与筛选选项接受 `connectedColumnIds`、`unconnectedColumnIds` 和 `incomingProjectIds`。前两者逐列取交集，入站项目选择沿用既有多选的并集语义；三组条件与其他字段筛选取交集。连接谓词在 SQL 使用 EXISTS / NOT EXISTS，先于计数和分页，规范化后的三个 ID 集合参与列表及选项游标指纹。没有增加连接排序或分组字段。

连接必须未解除、列未删除、对端工作项未删除；归档对端仍保留，与[最小卡片授权](../security/2026-09-30-connection-intake-and-card-visibility.md)一致。未连接筛选还要求列确实属于当前项目且有效，未知或外项目列返回空结果，避免把无效列解释为全项目匹配。入站项目选项按工作项去重计数，项目名称经 catalog 公开端口批量取得，不从 workitem 查询 catalog 表。

前端连接分组使用列目录与服务端 `INCOMING_PROJECT` 选项；同一列的已连接、未连接选择互斥。筛选保存在项目路由，可清除并用于表格、既有字段分组和看板列表请求；仪表板嵌入不显示或传递这些条件。连接列偏好仍由[表格体验](2026-09-30-connect-column-table-experience.md)拥有。

## Alternatives considered

- 对已加载行的 A6 缓存做过滤：会遗漏其他页，无法给出完整计数，故在 SQL 先过滤。
- 用连接 JOIN 直接扩展工作项行：同一事项多个连接会重复计数和分页，故列表使用 EXISTS，入站选项按项目和工作项去重。
- 把其他项目或已删除列视为无连接：可能使失效筛选意外匹配全部工作项，故保守返回空结果。
- 增加新的连接权限或任意项目信息端点：已有卡片授权与 catalog 最小项目端口足够，不扩权限和公开字段。

## Consequences

连接数量不改变工作项查询基数。删除、恢复和归档后的筛选结果以当前可读连接事实为准。当前游标绑定查询条件，不承诺连接事实变化前后的数据库快照。

`ConnectionFilterIT` 覆盖列交集、入站去重、计数、游标、删除恢复、归档与不可见项目；`ConnectionHttpIT` 验证请求参数及服务端鉴权。前端组件与容器回归覆盖状态选择、路由传递、服务端计数和清除。
