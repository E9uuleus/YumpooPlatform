# Agent Note: 页面加载提示分工

Status: implemented

## Problem

路由切换、首页查询和文档正文加载存在没有局部动画的等待阶段。仅以路由完成作为加载结束会早于页面主要数据就绪；全局请求计数又会把轮询当作用户等待。

## Decision

Web 与 Electron 主窗口共用顶部 3px 主题色细条。启动品牌画面关闭前不显示；原有局部遮罩、骨架屏与按钮提示保留。透明计时器和壳专用小窗不显示顶部条。

路由导航启动协调器，页面通过 usePageLoad().track 显式登记首次加载任务，路由提交和任务结束后等待渲染更新再收尾。导航代次隔离旧请求，组件卸载释放登记。后台轮询、保存和追加分页保持局部反馈。

显示延迟为 150ms，最短可见时间为 200ms。渐进动画上限为 90%，不宣称精确百分比；减少动态效果时显示静态提示。完成后淡出。

## Alternatives considered

- 仅监听路由：无法覆盖路由提交后的主要数据与文档正文。
- 拦截全部网络请求：轮询和预取会反复触发，与用户等待无关。
- 替换全部品牌遮罩：失去区域级操作阻塞与加载定位。

## Consequences

新增页面的主要加载需要显式登记，不能依赖网络拦截自动发现。进度条表示等待状态，业务错误仍由原页面处理；不修改服务端合同和桌面 IPC。
