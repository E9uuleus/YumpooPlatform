# Agent Note: 自定义 Charts 与组件独立数据范围

Status: implemented

## Problem

固定预设无法表达不同组件的坐标轴、指标和项目范围。单独的布局编辑模式、全屏入口及设置抽屉割裂了编辑与查看；在前端抓取全部工作项计算又会破坏分页完整性、权限交集和统一统计时点。

## Decision

常驻保存状态提示与人工版本冲突恢复由[自动避让与窗口独立保存](2026-09-19-dashboard-layout-autosave.md)部分替代；输入防抖、图表范围和设置预览保持本记录的规则。

全屏入口、明细编辑与保存恢复由 [仪表板保存恢复和统一展开视图](2026-09-18-dashboard-recovery-and-exploration.md) 部分替代；本 Note 继续拥有图表配置、统计口径及设置预览决策。

本决策部分替代 [私人仪表板](2026-09-16-personal-dashboards.md) 的“所有组件只能共享全局筛选”限制，其配置所有权、成员权限、父子计数与原始计时原则保持有效。组件范围按已连接且当前可访问的项目、全局条件、组件条件及点击的分类/系列逐层取交集。组件 projectIds 为 null 时继承连接项目，空数组表示显式不选任何项目，不能回退为全部。

现有 Widget 的可选 chart 字段存储结构化设置，继续使用 personal_dashboard 的 JSON，不迁移或重建已有仪表板。旧预设通过前后端适配器恢复原有统计口径和显示选项，编辑后可以转换为八种图表类型。类型切换保留兼容设置，隐藏的不适用系列、堆叠或气泡指标不参与查询与绘制。

仪表板查询接受未保存的 widgets 并按 ID 批量返回图表结果；reporting 只调用 WorkItemStatisticsQuery 公开端口。workitem 复用每工作项原始计时预聚合，用同一 asOf 计算活动计时，SQL 负责日期分桶、系列及耗时合计/平均/中位数/极值。平均值和中位数以匹配的工作项为样本，未记录耗时的工作项为零。分类排序值独立聚合，不能累加各系列的平均值、中位数或完成率。日期按选定时区分桶，周从星期一开始；截止和计划日期是本地日期，不做时区平移。明细查询携带同一组件配置和稳定的分类/系列键，显示名称与颜色修改不会改变过滤条件。

桌面网格始终允许拖动和缩放，12/6 列布局继续分别保存；最小列数根据可用宽度计算，允许图表达到方形附近的网格尺寸。网格单元保持既有 40px 高度，避免改变旧布局的物理含义；窄屏提供上下排序。新增/复制组件在抽屉关闭、网格布局完成后滚动并高亮，切换仪表板取消待定位请求。

组件设置使用带页面边距的大弹层，左侧预览、右侧折叠字段，窄屏上下排列。参考 [Monday Widget settings](https://support.monday.com/hc/en-us/articles/360001262665-The-Chart-Widget) 的分组设置和标签编辑入口，统一下拉菜单、36px 表单控件、图表类型选择、按钮及焦点态；长字段列表可以搜索，工作项类型使用多选标签。样式限定在组件设置及其弹出菜单内。有效编辑即时更新预览，查询防抖 250ms，自动保存防抖 650ms 并串行提交。空名称等输入中间态留在编辑器；查询失败保留上次结果并显示重试，保存失败保留本地草稿与同一幂等请求。版本竞争和保存状态显示遵循[自动避让与窗口独立保存](2026-09-19-dashboard-layout-autosave.md)，过期响应不能覆盖较新的编辑。

自定义外观的分类和拆分系列默认读取统计结果的 colorToken / seriesColorToken，状态、状态分类、优先级和工作项类型沿用原标签色；设置色块与所有适用图表（包含气泡图）共用 [chartColors](../../../../frontend/web-app/src/components/dashboard/chartColors.ts) 解析规则。只修改名称或顺序不会固化默认颜色，打开设置不产生颜色覆盖。用户明确选色才写入十六进制覆盖，恢复默认只清除该颜色覆盖并保留名称与顺序，随后继续跟随源标签色。

## Alternatives considered

- 继续为每种预设维护专用抽屉：坐标轴、过滤及显示设置会重复且行为容易分叉，因此统一为 Charts 配置和渲染器，保留预设作为快捷起点。
- 所有组件强制采用全局范围：无法在同一仪表板比较不同项目子集，因此允许组件进一步收窄，始终禁止扩大权限或绕过全局条件。
- 每次预览必须先保存：容易把半输入名称和无效设置写入持久层，因此查询显式接受有效草稿，保存仍遵守强 ETag。
- 在浏览器计算统计或合并系列中位数：会下载全量事项、受分页限制且产生错误聚合，因此由 workitem 直接统计。
- 根据屏幕尺寸改写网格行高：会改变现有持久布局的含义，因此保留行高并调整最小约束，图表内容自适应。
- 打开设置时把默认颜色复制进配置：会把继承色变成永久覆盖，源标签改色后无法跟随，因此显示时解析默认色，仅持久化用户明确的覆盖。

## Consequences

自定义 Charts 支持的字段限于现有业务维度，不是任意自定义字段系统；日期图展示当前事项状态的分布，不代表历史快照趋势。名称/颜色覆盖最多 500 项，组件数量、项目数量和明细分页上限沿用既有边界。耗时合计下钻列出有计时记录的事项；平均值/中位数/极值下钻包含零耗时样本。完成率指标卡下钻保持旧预设的已完成事项口径，分类完成率图的明细包含分母事项。

## Verification

DashboardHttpIT 在真实 PostgreSQL 验证旧配置、草稿查询及持久化、空范围与筛选交集、撤权、日/周/月及跨时区分桶、五种耗时计算、系列明细和气泡指标；模块架构检查验证 reporting 不越过公开端口。前端测试覆盖预设适配、稳定分类键、排序、非加性指标、查询防抖与过期响应、输入中间态、类型切换、空项目范围、串行保存、同键重试和冲突草稿保留。

浏览器使用独立临时数据库验证 390/1024/1280/1440 宽度、菜单展开/收起、浅深主题、画布边缘与工具栏、设置预览、独立项目及明细、添加/复制定位、拖动/缩放和刷新恢复；服务中断后重试保存、真实版本冲突另存副本均验证成功。新增定位等待网格动画结束，避免滚动被过早的画布高度截断；切换页面取消待定位的测试覆盖该异步边界。

本次通过 18 个前端仪表板测试、14 个客户端测试、5 个 DashboardHttpIT 集成测试和 16 个模块架构测试；OpenAPI、客户端生成一致性、前端 lint/类型检查/构建、Markdown 链接和 Agent Note 检查通过。全仓 lint 保留已有格式警告，构建保留已有大分块提示，均无错误。

2026-09-20 设置面板与默认配色调整通过 11 个测试文件的 70 个仪表板测试，覆盖四类标签颜色继承、名称覆盖不固化颜色、自定义颜色保留/恢复、拆分系列和七种图表绘制，以及新下拉框的数据绑定。浏览器核对真实标签色与设置色块一致，并在独立预览验证 390px 窄屏、浅深主题、下拉菜单及颜色选择器；深色选中项使用主题链接色以保持可读性。变更文件 lint、前端类型检查和生产构建通过，构建保留既有大分块提示。
