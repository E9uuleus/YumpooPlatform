# Agent Note: 工作项看板卡片

Status: implemented

## Problem

原看板只有按状态分列和拖动迁移：卡片只显示类别、编号、名称和优先级，修改字段必须打开详情；列头是纯文字，数量只是已加载条数；整个看板在一个滚动容器里，内容一多就把工具栏挤压变形；「隐藏已完成」等工具栏按钮在看板里被禁用。看板需要像表格一样直接编辑，并在高度固定的页面里浏览大量工作项。

## Decision

看板由[`WorkItemKanbanBoard.vue`](../../../../frontend/web-app/src/components/projects/WorkItemKanbanBoard.vue)（列布局、列头、滚动、懒加载、拖放目标、列尾新建行）和[`WorkItemKanbanCard.vue`](../../../../frontend/web-app/src/components/projects/WorkItemKanbanCard.vue)（单张卡片与展开的子项）组成。数据加载、状态迁移、字段修改与新建仍由 `ProjectWorkItems.vue` 负责，看板通过插槽渲染卡片，卡片通过事件调用表格已有的处理函数。

- **列：** 列头整块使用状态颜色，白字显示状态名与数量。数量取自 `listProjectWorkItemFilterOptions(field=STATUS)`，带当前筛选，与分组计数同源；计数未返回或失败时显示已加载数（还有下一页时带 “+”）。页面高度固定，看板占满剩余高度并横向滚动，每列以自身滚动区为根观察懒加载哨兵，提前 240px 加载下一页。工具栏与视图标题不参与纵向收缩。
- **卡片字段：** 跟随「隐藏」列设置与表格列顺序，显示类别、状态、优先级、截止日期、时长追踪；看板中「隐藏」因此可用。有色字段（类别、状态、优先级）为左侧 3px 色条标签，悬停时颜色从左向右铺满、文字变白，离开时从右向左褪去；截止日期与时长追踪为带字段图标的灰底标签，悬停加深。空字段只在悬停或聚焦卡片时以虚线占位标签出现。处理人在左下角，讨论与子项按钮在右下角，⋯ 菜单在右上角，复用表格行菜单。没有单独的编辑按钮：点击名称直接改名，点击卡片空白处打开详情。
- **编辑：** 点击标签打开与表格完全相同的弹窗：状态、优先级用 `WorkItemLabelPopoverContent`，类别用 `WorkItemContentPopoverContent`，截止日期与时长追踪使用各自单元格组件的 `variant="tag"`，只替换触发器外观。同一张卡片同时只开一个弹窗。
- **新建：** 列头 “+” 与表格「新增工作项」一致，以「新工作项」创建并直接改名；列尾「+ 新建工作项」输入名称创建并移到列末尾（仅当该列已全部加载）；行菜单「在下方创建新工作项」创建并移到该卡片之后。三者都用 `useWorkItemGroupCreate` 的 STATUS 逻辑：带新建默认值，状态以所在列为准，严格迁移，重试不会重复创建。完成后只重新加载该列和列头数量。
- **子项：** 子项按钮在卡片下方原地展开子项卡片（只显示名称，点击打开详情），末尾可添加子项；连接线使用与表格子项相同的颜色、线宽与圆角变量。
- **隐藏已完成：** 开关开启时（不论选择哪种效果），看板不显示也不加载被本人视为已完成的状态列；仪表板内嵌看板不受影响。规则归属见[工作项隐藏已完成](2026-10-19-work-item-hide-completed.md)。

## Alternatives considered

- **看板单独的卡片字段设置（Monday 的 Customize cards）：** 多一份需要保存和同步的配置；卡片字段与表格列同属“我想看哪些字段”，复用「隐藏」即可。
- **卡片上固定显示全部字段：** 字段多时卡片过高，也无法隐藏不关心的字段。
- **空字段始终显示占位：** 卡片噪音大；只在悬停时出现，既保持整洁又能直接设置。
- **子项按钮打开详情抽屉：** 实现更简单，但看不到父子结构；原地展开与表格的子项展开一致。
- **隐藏已完成在看板中淡化卡片：** 已完成状态的列整列都是已完成项，淡化整列没有意义；隐藏整列更直接，也减少加载。
- **在前端用已加载条数显示列数量：** 分页加载下只能显示 “25+”；改用分组计数接口得到准确数量。

## Consequences

看板与表格共用字段弹窗、行菜单、改名、新建默认值和子项加载，表格侧这些行为的修改会同时作用于看板。列数量多一次计数请求，失败时不影响看板。新建后的末尾放置依赖项目手动顺序与看板排序一致（看板按 rank 排序）；该列还有未加载的分页时不移动，新项按服务端默认位置出现。`WorkItemKanban.spec.ts` 覆盖列头、加号与列尾新建行、懒加载哨兵、卡片标签顺序与占位、详情/讨论/子项事件；`ProjectOverviewView.spec.ts` 覆盖看板拖放迁移。
