# Agent Note: 工作项列头菜单、列折叠与分组和添加行冻结

Status: implemented

## Problem

列操作集中于工具栏，用户在目标列上缺少直接入口。添加行和分组标题依赖 scroll 事件回写横向位移，合成器滚动先于 JS 时会先移动再回弹；表格底部 32px 留白也超出 12px 横向代理滚动条所需空间。

## Decision

主表所有内置列及分组视图重复列头提供设置、筛选、排序、折叠和分组入口；设置仅对状态、优先级与工作项类别开放，复用现有标签与颜色编辑器的编辑模式及弹层样式，定位于实际操作的列名单元格下方，不使用背景蒙版。保存期间不允许关闭，编辑器支持点击外部、Esc 和应用后关闭。筛选打开对应工具栏弹层。连接列保留原菜单，仅增加折叠列；子项表格沿用既有列头。名称列不可折叠，折叠列宽为 40px，以 ↔ 恢复原宽，collapsed 保存于现有表格本地偏好，不升级偏好版本。

主表内置列与连接列共用水平三点菜单按钮的尺寸、底色和悬停规则，按钮固定于单元格内部右侧。悬停、键盘焦点进入或菜单打开时为按钮让出文字空间，列名按剩余宽度省略；离开后恢复。内置列快捷排序与菜单同步出现，保留原有上方排序气泡的位置及已激活排序的提示。

列头菜单仅在打开时挂载浮层，避免分组重复列头同时挂载大量隐藏菜单；菜单动作与关闭后的视图偏好不受挂载时机影响。

添加行的引导条、复选框、名称输入与操作使用 position: sticky；el-table__append-wrapper 的 overflow 为 visible，使 sticky 以表体滚动容器为参照。原 JS 反向位移在 scrollLeft=300 时同步读到输入框从 161px 跳至 -139px，sticky 在滚动至 421px 后仍为 161px，采用浏览器原生冻结消除回弹。概览页 app-main 底部留白改为 12px，为既有横向代理滚动条保留空间。

分组标题、加载提示与其颜色引导条也使用 sticky 冻结，合并单元格的 .cell 允许溢出，使冻结参照表体滚动容器。标题及色条不再读取 JS 横向位移变量；该变量仍服务既有子项展开区域。1440×900 长表横滚从 0 到 671px 时，全部 7 个分组标题的 x 坐标均保持 373px，展开与收起状态均不再产生滚动回弹。

## Alternatives considered

- 继续在 scroll 回调抵消位移：JS 晚于合成器滚动，不能保证同步冻结。
- 为设置另建标签编辑器：增加目录保存和校验双实现，直接复用既有编辑模式。
- 使用居中的设置对话框与暗色蒙版：脱离列操作的上下文，沿用原编辑器的列下弹层。
- 折叠时删除列或丢弃原宽：会破坏恢复位置与用户偏好，保留列身份、宽度及 40px 入口。
- 扩展为 AI、复制、改类型、删除列或指定完成颜色：超出本次确认范围。

## Consequences

列头快捷排序仍可使用，菜单将已有工具栏能力带到列上；目录修改与表格显示偏好保持各自原有持久化。新增菜单组件复用设计令牌与图标体系。[字段分组](2026-09-14-work-item-field-grouping.md)的稳定行、草稿与分页规则保持有效。
