# Agent Note: 面向个人的跨项目工作选择器与常驻计时窗

Status: implemented

## Problem

以当前项目为入口的计时列表要求用户先切换工作台和项目，查找成本高；进入项目即弹窗又会打断无关操作。桌面主窗口关闭即进入退出流程，使小窗口无法承担常驻工作入口。浏览器的弹窗权限和置顶能力也不适合作为 Electron 交互的上限。

## Decision

计时器以个人工作为入口，默认合并最近计时与分配给我的工作，同一事项只出现一次；搜索工作项标题、编号或项目名称/代码时覆盖全部可计时项目。按最近计时、本人分配、更新时间和 ID 稳定排序，当前事项在焦点卡显示并从候选中移除。暂停后短暂保留保存反馈，随后恢复候选列表。选择即开始或原子切换，键盘支持方向键、Enter 和 Escape；表格单元格仍一键启停，不增加确认。计时成功后收起为悬浮球，圆面只常显本次时长和一个暂停/继续按钮，不显示项目名或工作项名。项目与工作项通过侧边 SVG 入口向屏幕空余的一侧展开；侧边详情仅保留更换工作，不提供置顶或隐藏按钮；完整选择器也不显示右上角隐藏按钮。隐藏继续由托盘或 Escape 提供，置顶由完整选择器或托盘提供。侧边详情高度收敛为最多 112 像素，随小尺寸球体缩减，原生裁剪和悬停区域同步收紧。

候选行只显示类别图形、标题和项目名，移除首字符方块、来源标签、累计说明、编号副行与操作教学。类别使用后端稳定 `contentCode` 映射任务、需求与缺陷 SVG，颜色复用内容目录的 `contentColorToken` 和现有标签色令牌；名称改动不改变图标，自定义类别使用独立通用图形。两个新增字段可选，旧响应仍可显示通用图形。球体使用细圆环、柔和阴影与留白，运行时圆环缓慢转动，暂停时静止；数字滚动、按钮按压与保存勾选使用 CSS/Vue 过渡，并尊重系统减少动态效果的偏好。在整个球面停留 350 毫秒后显示详情入口与右上角缩放手柄；移入详情保持展示，离开球体和详情 250 毫秒后收起，键盘聚焦与触摸入口仍可用。不再围绕球体常驻查找、置顶、隐藏等卫星按钮。选择器、焦点卡与侧边详情均不再为工作项添加额外悬停 Tooltip 或原生 `title` 提示。

`GET /me/time-tracker/candidates` 是 actor-scoped 只读查询，PERSONAL/ALL 范围及分页有明确上限。workitem 通过 catalog 的公开 `ProjectAccessSnapshotQuery.findWritableProjects` 获取当前公司内、活动成员可写且未归档的项目，随后在本模块 SQL 内搜索并分页。最近信息来自本人未删除的 TIMER 会话，累计来自本人原始计时记录，不在客户端逐项目扫描，也不新增推荐或计时持久化事实。公司管理员的只读可见性不因此扩大为计时权限；真正启停仍由既有命令校验授权和版本。

Electron 使用一个共享认证 partition 的透明无边框小窗口：球体默认 176 × 176，手柄等比例调整至 128–280，选择器为 392 × 520。紧凑窗口额外预留 40 像素顶部及两侧各最多 224 像素透明空间，`TimerOrbLayout.canvas` 提供球体偏移与画布尺寸；详情和名称提示显隐只改变内容与原生命中区域，不再反复调整窗口位置和大小。重复进入紧凑模式或显示已经可见的非激活浮窗不会重新设置几何或显示窗口，以免原生旧帧与异步 Vue 布局不同步导致闪烁。时长和圆心背景均可原生拖动，启停与其他按钮排除拖动；手柄捕获指针并按帧请求尺寸变化，也支持方向键调整。尺寸通过仅可信小窗可调用的 `orb-layout` IPC 校验，主进程根据实际显示器工作区决定详情方向、尺寸与位置，兼容负坐标显示器；小屏会限制球体尺寸并为详情留出空间。移动结束后延迟 120 毫秒重新约束透明画布，以适应屏幕另一侧；详情开关本身不触发窗口移动。缩放尽量保持球体左下位置，切换选择器保持球体右下位置，受屏幕边界限制时作必要移动；球体大小在本次应用进程中保留。Windows/Linux 的原生裁剪由圆形与可见详情卡组成，选择器恢复矩形区域。可切换置顶，隐藏不暂停。工具栏主动打开选择器，表格启动时非激活地显示悬浮球，进入项目不自动弹出。

桌面启动后，首次收到已登录账户状态即非激活地显示悬浮球，每个进程只自动显示一次；后续状态轮询不会重新打开用户隐藏的球体。原生拖动区域不可靠地派发 DOM 悬停事件，因此主进程仅在紧凑窗口可见时每 100 毫秒检查光标是否位于球体或详情中，通过受控通知只发送变化后的布尔值，窗口销毁或应用退出时释放轮询。

计时运行期间，悬停球体后在上方显示带小圆点的工作项名称圆角提示，单行超长省略；停留期间持续展示，移开鼠标或暂停计时后消失。已在球上悬停时启动计时会立即显示；轮询与重复模式通知不重播动画，同一提示请求在等待回执期间也会去重。提示以淡入、轻微上浮与缩放入场，淡出下移退出；退出动画完成后才释放提示区域，减少动态效果时立即完成过渡。桌面使用预留的顶部画布，Web 与画中画仍同步调整顶部空间并尽量保持球体底部位置。提示请求与布局响应使用本地序号忽略过期回执，快速暂停不会让延迟确认重新显示旧提示。

托盘归属于 YumpooPlatform 应用，使用与主界面品牌一致的蓝底 Y 图形和应用名；单击/双击恢复主窗口，右键显式展开应用菜单。菜单包含打开应用、查找工作项、暂停并保存/继续最近工作、显示悬浮球/隐藏计时器、置顶及明确退出。未登录时查找与显示入口恢复主窗口。关闭主窗口只隐藏，默认置顶状态只保留在本次应用进程中；托盘与浮窗的置顶状态同步。非置顶紧凑窗失焦时，仅在仍可见的前提下抬升一次普通 Z 序，避免切换焦点时沉到桌面之后；不调用聚焦、不改为永久置顶、不重新显示主动隐藏的窗口。它仍遵循普通窗口层级，之后新出现的前台窗口可以遮挡它。

主 renderer 在隐藏时继续每五秒向服务端校准，并是托盘状态的唯一发布者；小窗口和表格复用同一计时 composable，以受控 IPC/BroadcastChannel 通知刷新。托盘只把带请求标识的明确启停动作交给主 renderer，命令处理共用 busy、幂等键和 ETag，暂停绑定预期 session ID。过期或断线状态禁用托盘启停；超时与失败打开选择器提示核对，不盲目重放或假定暂停成功。命令确认成功后立即保留服务器结果、结束按钮等待，后续校准在后台继续，校准失败不改变已确认结果。退出仍沿用停止并退出、继续计时并退出、取消的确认握手。

保存反馈只来自服务端接受的运行会话到停止状态的版本推进；请求等待、失败和过期响应不产生成功提示。`savedAt` 是共享 composable 和受控桌面状态中的瞬时界面信号，不是持久化计时事实；新窗口可承接近期确认，提示显示后自动消失，同一确认不会因轮询或置顶再次播放，新计时和账户生命周期重置会清除旧提示。表格或托盘停止时可恢复隐藏的悬浮球提供反馈，已打开的选择器保留原界面并显示勾选。失败时展开错误与重试入口。

Web 使用相同 TimerPanel 与计时状态。用户主动打开时尝试 Document Picture-in-Picture，同时保留可用的页内面板；不支持或拒绝时直接使用可拖拽的非模态页内浮窗，不再开启普通浏览器弹窗。页内拖动捕获指针，侧向展开、缩放和视口变窄时重新约束尺寸与位置；画中画使用同一内容并请求宿主调整窗口尺寸。画中画窗口由宿主关闭时回到页内，主动隐藏则关闭当前入口；过期的画中画授权不重新显示已隐藏面板。主题变化同步到画中画，表格计时无需画中画授权即可显示紧凑反馈。

本记录部分取代[原始计时与跨端退出决策](../architecture/2026-09-07-work-item-time-tracking.md)中的项目自动弹窗、Web 普通弹窗降级及主窗口关闭行为。该记录继续拥有单人单计时、UTC 口径、历史修正、权限、锁序和退出后的计时事实。

## Alternatives considered

- 保留项目列表并增加项目下拉：仍要求先理解项目归属，不能缩短跨项目找工作的路径。
- 单独罗列最近、分配给我和当前事项：同一工作重复出现；合并候选，项目名保留上下文。
- 以类别名称首字或当前名称匹配图标：重命名后标识不稳定；采用现有稳定代码和颜色令牌。
- 点击停止即显示保存成功：网络失败、并发冲突或响应丢失时可能误导；以服务端确认驱动反馈。
- 切换前逐次确认：用户已经明确选中目标；使用原子切换与版本校验保护记录，保留一键操作。
- 托盘直接携带凭据请求后端：复制鉴权、CSRF 与重试职责；选择主 renderer 持有业务会话和发布状态。
- 关闭主窗口时销毁 renderer，只保留托盘：需要另建服务端连接和认证生命周期，暂不承担这部分成本。
- Web 使用同源普通弹窗作为兜底：会受到拦截、焦点和窗口管理限制；页内复用更可靠，也不限制原生桌面窗口。

## Consequences

新候选接口和生成 SDK 为增量变更；先发布后端，再更新 Web 与桌面。没有数据库迁移，回退交互不影响会话与历史记录。关闭主窗口后保留 renderer 会占用内存并持续校准，这是托盘复用现有会话的成本；显式退出才释放应用。

候选使用 offset 分页，工作分配或最近顺序在翻页期间变化时可能改变后续页；客户端按工作项 ID 去重，重新搜索或展开从第一页校准。当前状态、授权与切换结果仍以服务端为准。断网后已有计时继续，不能离线确认新的启停；本次未引入离线写队列。

## Verification

PostgreSQL HTTP 集成验证覆盖候选范围、稳定类别代码与颜色、跨项目搜索、字面通配符、分页、撤权和归档过滤，并回归单人并发、跨项目原子切换、撤权后停止、历史修正与幂等。Web 回归覆盖类别重命名、精简显示、跨项目键盘选择、详情入口、圆心拖动、指针缩放与释放、窄屏约束、无额外悬停提示，以及成功反馈、过期、失败、慢速校准、跨窗口和账户重置。Electron 回归覆盖圆形/详情裁剪、方向选择、大小保留、负坐标显示器、尺寸与来源校验、应用托盘右键回调、主窗口恢复、置顶同步、命令确认和退出。

2026-09-10 验证：前序 Web 全量 343 项（`--maxWorkers=2`）通过；本轮启动显示、整球悬停与名称提示修正通过计时面板/宿主 23 项、Electron 38 项及 IPC/工作区边界 10 项回归。此前同一变更的 SDK 14 项、后端计时 HTTP/服务 7 项和 OpenAPI lint/示例/生成一致性已通过，本轮不修改业务接口。类型检查、构建与文档门禁通过；本轮修改文件 lint 零错误、零警告。

隔离样例下实际浏览器验证了圆面静止布局、拖住圆心移动、右上手柄缩放、侧向详情、换工作后收起、暂停后的保存反馈，以及真实主题令牌下的深色/窄屏/最小尺寸布局；悬停提示的实际颜色为深色背景与白字。另验证整球延迟呼出、移入详情保持、移出自动收起，以及启动后的圆角名称提示和超长省略，页面没有运行时错误。2026-09-11 通过 computer-use 操作隔离 Electron 窗口，观察了详情展开、启停及名称提示入场时球体位置保持稳定；浏览器进一步确认提示的过渡样式与超长省略。原生鼠标拖动、缩放和系统托盘图标入口仍保留人工验收缺口；拖动后的方向、启动显示、光标通知、窗口几何、裁剪和菜单回调已有自动化覆盖。
