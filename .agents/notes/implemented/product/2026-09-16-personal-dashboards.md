# Agent Note: 私人仪表板与跨项目统计边界

Status: implemented

## Problem

工作台需要个人跨项目数据视图。若把项目表格的共享默认配置改成个人视图，或把管理员治理可见性直接用于私人仪表板，会混淆配置所有权和成员授权；若直接关联计时明细统计事项，多条记录会放大数量，父子耗时也可能重复汇总。

## Decision

reporting 通过 V54 personal_dashboard 保存当前公司、当前用户拥有的多个私人仪表板，以及连接项目、组件设置、宽屏/中等画布布局和统一筛选。配置命令复用强 ETag、幂等键与既有 Session/CSRF，读取、统计、编辑和软删除均先验证所有权。公司管理员不能读取他人的私人配置。

catalog 的 MemberProjectQuery 只提供当前主体具有 ACTIVE 成员关系的同公司项目，不沿用管理员只读旁路。workitem 的 WorkItemStatisticsQuery 在每次聚合和明细查询重新交集连接项目与成员权限；reporting 仅调用公开端口，不读取其他模块表。失去访问权限的连接仅保留 ID 与不可访问标记，不返回名称、编码或数据。归档项目保持成员可读，新增连接必须当时有权限。

采用全事项口径：父项与子项各计一次，默认排除已删除及自身已归档的事项；父项归档不会改写子项自己的归档事实。完成率为 DONE / 所有匹配事项，包含已取消项的分母，空集合为零。成员维度指当前处理人，不是计时记录创建者。

计时会先按事项聚合有效原始记录再连接事项，运行中记录使用同一 asOf；不累加父项的派生子项耗时。截止日期约束事项，不截断历史计时。具体状态来自项目标签目录，仅代码、分类、名称及颜色一致时合并，或由组件显式切换为四个兼容分类。

前端使用 GridStack 的碰撞、拖动和缩放能力，Vue 持有组件内容；12 列和 6 列布局分别持久化，窄屏采用阅读顺序。仅用户拖动/缩放结束触发保存，视口变化不写回。ECharts 按需加载 SVG 图表，复用现有设计令牌、状态色和成员组件。所有组件共享全局筛选。

## Alternatives considered

- 仅将配置存入 localStorage：无法跨设备保留、可靠隔离账号或处理多窗口并发，因此仅用它记录最近访问的仪表板 ID。
- 复用 CompanyAdmin 的项目可见性：私人仪表板要求统计本人所属项目，管理员治理权限会扩大范围，因此增加明确的成员查询端口。
- 前端抓取全部工作项或逐组件请求统计：产生分页遗漏、大量请求和统计快照不一致，因此后端一次返回图表聚合与筛选选项，明细单独分页。
- reporting 直接跨模块关联 SQL：侵入业务真源职责；聚合 SQL 保留于 workitem，由公开端口提供能力。
- 自研自由画布和拖拽算法：需重复处理碰撞、响应式和触摸交互；选择有界网格并保存两档布局，避免引入第二套拖拽基础设施。
- 默认只统计根项或累计父项汇总耗时：与本次确认的全事项口径不符，且会重复统计子项投入。

## Consequences

新增配置与 API 需保持后向兼容；后续共享、导出或历史趋势必须重新明确权限及数据口径。当前最多连接 100 个项目、40 个组件，筛选列表每字段最多 500 项，明细分页最多 100 项。自动保存串行化并保留冲突草稿；刷新失败保留上一次数据并明确标识。

本决策补充 [工作项核心合同](../architecture/2026-08-22-work-item-core-contract.md)、[父子关系](../data/2026-08-28-work-item-parent-child-relations.md)、[项目标签目录](../data/2026-08-26-project-work-item-label-catalog.md) 和 [原始计时](../architecture/2026-09-07-work-item-time-tracking.md)。既有“不要创建私人工作项表格视图”的选择针对 Content 共享默认，本次独立仪表板不取代它；没有需要归档的活动 Note。

## Verification

DashboardHttpIT 在真实 PostgreSQL 验证私人所有权、版本冲突、幂等重放、撤权、父子数量、原始计时、成员/未分配筛选、归档及分页。前端测试覆盖独立布局无重叠、状态合并、下钻、连续修改串行保存、同键重试和冲突保留。浏览器已验证两项目仪表板、拖拽、缩放、刷新恢复和成员筛选明细。

完整后端回归通过：454 个单元测试（1 个既有跳过）、221 个集成测试，以及 96MB 有界堆验证。浏览器另验证组件增删撤销、多仪表板切换、设置抽屉、390/1024/1280 宽度和深色主题。新建时等待配置加载的回归用例防止连接弹窗沿用上一仪表板选择。Windows 全量 Maven 使用进程级 jdk.net.unixdomain.tmpdir 参数规避 Java 本地回环路径问题。
