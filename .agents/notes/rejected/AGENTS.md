# AGENTS.md — Rejected Agent Notes

本目录中的 Agent Note 保存已经讨论但未采用的提案。遵循[根规则](../../../AGENTS.md)和[统一格式](../README.md#文件格式)。

拒绝原因必须写在 `Status: rejected — <one-line reason>` 中，正文保留被讨论的方案和真实替代方案。不得把 rejected Note 改写成 implemented 决策；后来采用相似方案时创建新的 Agent Note 并交叉链接。

rejected Note 永不归档。只有当它仍能阻止可信且有意义的错误时才保留；方案已过时、不再可能或已由新决策彻底解决时，删除该文件并修复活动入链。
