# AGENTS.md — Proposed Agent Notes

本目录中的 Agent Note 描述尚未完整交付、等待评审的长期提案。遵循[根规则](../../../AGENTS.md)和[统一格式](../README.md#文件格式)。

提案可以包含实施步骤、开放问题和未来时表达，但必须明确问题、方案、真实替代方案、验收标准与风险。部分实现仍保持 proposed，直到验收标准对应的机制已经交付。

proposed Note 只能迁移为 implemented 或 rejected，永不归档。迁移为 implemented 时必须把计划式正文改写为实际交付事实；不再推进时迁移为 rejected，并在状态行写明原因。
