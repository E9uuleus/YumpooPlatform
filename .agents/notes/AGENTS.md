# AGENTS.md — Agent Notes

Agent Notes 是由 Agent 编写和维护的长期提案与决策记录。进入本目录后，遵循[治理契约](README.md)及对应生命周期目录中的局部说明。

新建 Agent Note 前必须搜索活动目录中是否已有同一决策、机制或被拒绝方案的记录，并使用 [`archive-agent-notes`](../skills/archive-agent-notes/SKILL.md) 判断 supersession。部分取代时保留双方并交叉链接；完整取代时，新 owner 吸收旧记录全部独特理由、替代方案和约束后，将旧 implemented Note 归档。

[`archived/`](archived/AGENTS.md) 中已由 manifest 封存的 Note 是冻结历史，不得修改，也不得作为当前实现的权威来源。
