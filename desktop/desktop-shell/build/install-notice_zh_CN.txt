Yumpoo Desktop 安装须知与隐私说明

Yumpoo Desktop 是 Yumpoo 平台的公司内部桌面客户端，仅供本公司员工工作使用。

一、安装方式
· 只为当前 Windows 用户安装，不需要管理员权限。默认安装到 %LOCALAPPDATA%\Programs\YumpooDesktop，下一步可以更改。
· 创建开始菜单快捷方式（含「安全模式」）和可选的桌面快捷方式，在当前用户的注册表中登记卸载信息和 yumpoo: 登录回调协议。默认不开机自启，可在客户端偏好设置中开启「登录时启动」。

二、网络访问
· 网页、接口和自动更新只连接公司服务器 https://wecom-dev.yumpoo.com。登录时用系统默认浏览器打开企业微信官方扫码页。
· 唯一例外：内置拼写检查首次启动时从 Google 下载服务器（redirector.gvt1.com）下载一份英文词典，请求不带账号信息或输入内容。
· 不含第三方统计或广告。访问公司服务器时附带客户端类型和版本号；检查更新时附带一个本机随机生成、与账号无关的标识。

三、本机数据
· 勾选「7 天内免登录」时，登录凭据经 Windows 数据保护（DPAPI）加密保存在本机，只有当前 Windows 用户能解密；不勾选则不保存。
· 日志会去掉链接参数、凭据和消息内容，最多约 15 MB；崩溃转储只保存在本机，不会自动上传。
· 你主动导出的「诊断包」含日志和崩溃转储，崩溃转储可能含有内存片段，请只发给管理员。

四、自动更新
· 客户端自动检查和下载更新，核对公司签发的更新授权后在退出时静默安装。可在偏好设置中关闭自动下载，改为手动下载。

五、风险提示
· 安装包暂未进行 Windows 代码签名，可能出现「未知发布者」提示；开启了「智能应用控制」的电脑无法运行。请只从 https://wecom-dev.yumpoo.com/download 下载，并核对页面上的 SHA-256。
· 多人共用的电脑，登录时取消勾选「7 天内免登录」，离开前在客户端内退出登录。

六、卸载
· 在「设置 → 应用」中卸载。程序、登录凭据、缓存和日志都会删除，只保留计时器、提醒与桌面偏好文件。
