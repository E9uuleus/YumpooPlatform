读完你会知道：用户怎样登录、会话怎样保存与失效、每个请求怎样被授权，以及桌面壳的加固要点。本页不包含任何密钥或配置值。

## 登录

- **Web**：浏览器跳转企业微信 OAuth 授权页，回调校验 `state` 与 nonce 后建立会话。
- **桌面**：客户端向服务端申请一次性登录尝试（PKCE，带随机 `state`），在系统默认浏览器打开扫码页；扫码后浏览器经 `yumpoo:` 协议把一次性授权码交回客户端，客户端核对 `state` 后换取会话。客户端自己不连接企业微信。
- **本地开发**：`local` profile 下可启用本地登录夹具，只允许回环地址，不能与企业微信同时启用。

## 会话

- 会话是**数据库里的不透明会话**：浏览器只持有随机令牌，数据库只保存它的 HMAC 指纹，签名密钥可以轮换。
- Cookie 使用 `__Host-` 前缀（Secure、Path=/、不带 Domain）。
- 默认**闲置 8 小时**失效，**绝对时长 7 天**。勾选「7 天内免登录」时闲置期限等于绝对期限。
- 桌面客户端勾选免登录时，用 Windows DPAPI 加密保存会话凭据；不勾选则不落盘。

决策背景见 [会话保持与桌面防护](../../../../../../.agents/notes/implemented/security/2026-10-19-session-remember-and-desktop-guards.md)。

## CSRF

写请求必须携带与会话绑定的 XSRF 令牌。已认证会话的 CSRF Cookie 缺失或失效时，服务端用会话密钥确定性地派生修复令牌，并发请求会收敛到同一个令牌，而不是互相覆盖，见 [CSRF 收敛修复](../../../../../../.agents/notes/implemented/security/2026-08-22-convergent-csrf-repair.md)。

## 授权

- **每个请求**都会复核账号状态和授权版本：账号停用、角色变更会让旧会话立即失效。
- 全局角色是单一层级：平台管理员 ⊇ 公司管理员 ⊇ 普通成员；项目负责人与项目成员是项目级关系，见 [三级平台角色](../../../../../../.agents/notes/implemented/security/2026-09-25-platform-role-tiers.md)。
- 角色变更、账号启停等敏感操作要求 15 分钟内的近期认证。
- 无权访问的项目与工作项返回 404，不暴露是否存在。

## 桌面壳加固摘要

- 渲染进程开启沙箱与上下文隔离、关闭 Node 集成；网页只能通过 preload 桥调用固定接口，主进程逐个校验调用来源。
- 只允许导航到本站；新窗口与下载一律拒绝（导出经主进程保存对话框）；证书错误一律拒绝。
- Electron fuses 关闭 RunAsNode 等调试入口，开启 asar 完整性校验。
