Yumpoo 的权限分两层：**公司里的角色**决定你能看到哪些模块，**项目里的身份**决定你能在某个项目里做什么。

## 公司里的角色

三种角色逐层包含：平台管理员拥有公司管理员的全部能力，公司管理员拥有普通成员的全部能力。

| 角色 | 谁来授予 | 能做什么 |
|---|---|---|
| 普通成员 | 通讯录同步进来的在职成员默认是普通成员 | 使用首页和工作台：参与项目、处理工作项、计时、仪表板、收件箱 |
| 公司管理员 | 平台管理员在「公司管理 → 成员与角色」中授予 | 额外使用「团队」和「公司管理」：成员与角色、工作日历、定时任务、活动日志、团队视图 |
| 平台管理员 | 由已有的平台管理员授予；首位平台管理员在部署时设置 | 额外使用「运维」：运维中心的组件状态、主机、会话、日志与告警 |

每位成员同一时间只有一种角色。角色变更后，对方需要重新登录才会看到新的入口。

## 模块栏里你会看到什么

左侧模块栏随角色变化：

| 模块 | 普通成员 | 公司管理员 | 平台管理员 |
|---|---|---|---|
| 首页 | ✓ | ✓ | ✓ |
| 工作台 | ✓ | ✓ | ✓ |
| 团队 |  | ✓ | ✓ |
| 公司管理 |  | ✓ | ✓ |
| 运维 |  |  | ✓ |

## 项目里的身份

| 身份 | 能做什么 |
|---|---|
| 项目负责人 | 管理项目设置、添加或移出成员、结束、归档或删除项目，以及项目成员能做的一切 |
| 项目成员 | 创建和编辑工作项、讨论、上传附件、在项目里计时；可以在项目菜单中退出项目 |

一个项目只有一位负责人。负责人可以在项目「成员」页把负责人转交给另一位成员，公司管理员也可以；负责人和公司管理员都可以添加或移出项目成员。负责人需要先转交负责人才能退出项目。

## 看不到某个项目

::: tip 这是权限隐藏，不是故障
你只能看到自己参与的项目。打开一个你无权访问的项目链接时，页面会显示“找不到”，而不是“没有权限”，这样项目是否存在也不会被泄露。需要访问时，请联系项目负责人把你加入项目。
:::

公司管理员可以在「公司管理 → 项目」里看到全公司的项目总览。
