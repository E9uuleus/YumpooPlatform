---
title: 术语表
description: 界面中常见的名词，以及它们在哪里出现。
order: 40
audience: [member]
---

| 术语 | 含义 | 在哪里出现 |
|---|---|---|
| 工作台 | 你日常工作的模块：仪表板、我的工时、管理项目、归档项目和你参与的项目 | 模块栏「工作台」 |
| 项目 | 组织工作项与成员的单位，有一位负责人 | 工作台 →「管理项目」 |
| 工作项 | 项目里要完成的一件事，有状态、优先级、处理人、截止日期等字段 | 项目 →「工作项」 |
| 类别 | 工作项的类型，例如需求、缺陷；每个项目可以维护自己的类别 | 「工作项类别」列、项目设置 |
| 状态标签 | 工作项所处阶段，例如未开始、进行中、已完成；每个状态属于一个状态分类 | 「状态」列、看板列 |
| 优先级标签 | 工作项的紧急程度 | 「优先级」列 |
| 子项 | 挂在某个工作项下的一级子工作项 | 工作项名称左侧的展开按钮 |
| 连接列 | 把本项目工作项与其他项目工作项关联起来的列，两边都能看到 | 表头最右侧「+」 |
| 处理人 | 负责某个工作项的成员，一项最多 20 位 | 「处理人」列 |
| 计时 | 从开始到停止记录在某个工作项上的时间 | 表格「时长追踪」列、右下角「开始工作」 |
| 并行计时 | 同时给多个工作项计时，这段时间按项数平均计入每一项 | 计时面板 |
| 我的工时 | 你每天记录的工时月历 | 工作台 →「我的工时」 |
| 我的一天 | 某一天的时间线，用来补录和调整工时 | 我的工时 → 点击日期 |
| 标准工时 | 某个工作日应记录的工时，由公司工作日历决定 | 我的工时、首页工时日历 |
| 工作日历 | 公司维护的工作日、休息日、法定节假日和补班安排 | 公司管理 →「工作日历」 |
| 加班 | 在休息日或法定节假日记录的工时 | 团队 →「加班统计」 |
| 团队视图 | 公司管理员查看成员工时、加班和当前任务的模块 | 模块栏「团队」 |
| 仪表板 | 你自己的统计看板，由图表和表格组件组成 | 工作台 →「仪表板」 |
| 收件箱 | 汇总和你有关的通知 | 顶栏收件箱按钮 |
| 页面导览 | 指着界面元素逐步讲解的引导，可以随时重看 | 顶栏「查看本页引导」按钮 |
