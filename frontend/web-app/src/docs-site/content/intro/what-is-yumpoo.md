Yumpoo 工作中台（YumpooPlatform）是面向公司内部团队的项目协作与工时平台。你用企业微信扫码登录，在同一个工作空间里管理项目和工作项、和同事讨论、记录工时，再从仪表板和团队视图看到整体进展。

## 它能做什么

| 能力 | 一句话说明 |
|---|---|
| 项目协作 | 项目、成员和工作项类别；表格与看板两种视图，支持分组、筛选、排序、子项和跨项目连接。 |
| 讨论与附件 | 工作项详情里写富文本描述，两级讨论、@提及同事、置顶，上传附件。 |
| 计时与工时 | 一键计时，可以同时计时多项；「我的工时」月历和「我的一天」时间线用来查看、补录和调整。 |
| 统计 | 私有仪表板与自定义图表、项目统计，导出 PDF 或 Excel。 |
| 通知 | 收件箱汇总 @提及、回复、指派、成员变动和工时提醒；桌面端还会弹出提醒。 |
| 桌面客户端 | Windows 客户端提供悬浮计时、托盘快捷工时小窗和自动更新。 |
| 公司管理 | 成员与角色、工作日历、定时任务、活动日志和团队视图。 |
| 运维中心 | 平台管理员查看组件状态、主机指标、在线会话、运行日志与告警。 |

详细的能力清单见 [核心能力](capabilities.md)。

## 面向谁

- **团队成员**：在项目里处理工作项、记录工时、和同事协作。
- **公司管理员**：维护成员与角色、工作日历和定时任务，在团队视图里查看成员工时与加班。
- **平台管理员**：除公司管理外，还负责运维中心。
- **开发者**：参与本仓库的开发与交付，见 [本地开发](../start/developer.md) 和 [架构总览](../architecture/overview.md)。

不同角色在界面上看到的入口不同，见 [角色与权限](roles.md)。

## Web 与桌面端

Web 和桌面客户端是**同一个在线应用**：桌面客户端加载的就是公司部署地址上的 Web 页面，另外提供悬浮计时、托盘和系统通知等桌面能力。两端的数据完全一致，都需要连接服务器才能使用。

## 暂不支持

::: info 这些能力目前没有
- **工时提交与审批**：工时随记随存，没有提交、退回或审批流程。
- **离线使用**：断网时 Web 和桌面端都不能读写数据。
- **多公司**：一个部署只服务一家公司，账号来自这家公司的企业微信通讯录。
:::
