工作项是项目里要完成的一件事。项目的「工作项」页提供**表格**和**看板**两种视图：表格适合批量编辑，看板适合按状态推进。

## 入口

进入任一项目，二级导航「当前项目 → 工作项」。页面左上角的「表格」「看板」切换视图。

## 单元格编辑

在表格里点击单元格就能修改：状态、优先级、处理人、截止日期、工作项类别等。

- 一个工作项最多 **20 位处理人**，第一位是主处理人。
- 状态按项目的工作流切换；某些状态要求填写说明时会弹出输入框。
- 点击工作项名称旁的讨论图标打开详情，见 [讨论、附件与动态](collaboration.md)。

## 工具栏

| 按钮 | 作用 |
|---|---|
| 搜索 | 按名称或编号搜索工作项 |
| 处理人 | 按项目成员筛选 |
| 筛选 | 按截止日期范围、最后更新时间、计时状态和累计时长等条件筛选 |
| 排序 | 按多列排序，可以随时「清除」 |
| 隐藏 | 选择要显示的列 |
| 分组 | 「按字段分组」：状态、优先级、工作项类别或时长追踪列 |
| 隐没已完成 | 淡化本人定义为已完成的工作项 |
| ◷ 小计时器 | 打开悬浮的小计时器（计时器关闭时不显示） |

::: info 这些设置只影响你自己
筛选、排序、隐藏的列、分组、行高、固定列和条件着色都是你个人的表格设置，不会改变同事看到的表格。
:::

## 隐没已完成

打开「隐没已完成」后，已完成的工作项会淡化显示但仍保留在原位，方便你专注于未完成的事。哪些状态算“已完成”可以在同一个菜单里按项目自己定义（「本项目中视为已完成的状态（仅自己）」）。

## 快速添加

在表格底部的「添加工作项」输入名称：

- `Enter` 创建；
- `Shift+Enter` 创建后留在输入框里继续添加下一条。

表格按字段分组时，每组底部都有「添加工作项」，新工作项会落在该组里。你还可以在「表格设置 → 新建默认值」里设置新工作项的默认状态、处理人等字段。

## 批量操作

勾选多行后，表格底部出现批量操作栏：

| 操作 | 说明 |
|---|---|
| 编辑已选行 | 编辑任意一个已选单元格，可同步修改所有已选行 |
| 复制 | 复制所选工作项 |
| 移动 ▾ | 「置顶」「置底」调整手动顺序（需要先清除排序） |
| 转为子工作项 | 把所选工作项挂到另一个工作项下 |
| 归档、删除 | 归档后从列表隐藏，可以通过工作项链接恢复 |

## 子项与连接列

- **子项**：工作项可以有一级子工作项。点击名称左侧的展开按钮查看；行菜单里可以「转为独立工作项」。
- **连接列**：点击表头最右侧的「+」添加跨项目连接列，把本项目工作项与其他项目的工作项关联。连接是双向的，两个项目的表格里都能看到对方。

## 列头菜单

点击列头可以升序、降序或清除排序，状态、优先级、工作项类别和时长追踪列还可以直接作为「分组依据」。时长追踪列的列头菜单里也能开关「使用计时器」。

## 看板

看板按状态分列，拖动卡片即可推进状态。看板不支持分组和隐没已完成。

## 常见问题

::: details 为什么我不能拖动调整顺序？
表格正在按某列排序时，手动顺序不可用。先在「排序」里清除排序。
:::

::: details 为什么快速添加按钮是灰的？
项目已归档、项目没有可用的工作项类别，或你不是项目成员时，不能添加工作项。
:::
