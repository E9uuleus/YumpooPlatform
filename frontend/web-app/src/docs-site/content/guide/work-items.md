工作项是项目里要完成的一件事。项目的「工作项」页提供**表格**和**看板**两种视图：表格适合批量编辑，看板适合按状态推进。

## 入口

进入任一项目，二级导航「当前项目 → 工作项」。页面左上角的「表格」「看板」切换视图。

## 单元格编辑

在表格里点击单元格就能修改：状态、优先级、处理人、截止日期、工作项类别等。

- 一个工作项最多 **20 位处理人**，第一位是主处理人。
- 状态按项目的工作流切换；某些状态要求填写说明时会弹出输入框。
- 点击工作项名称旁的讨论图标打开详情，见 [讨论、附件与动态](collaboration.md)。

## 工具栏

| 按钮 | 作用 |
|---|---|
| 新增工作项 | 在表格顶部创建一条「新工作项」，名称直接进入编辑（仅表格视图）；右侧的 ▾ 菜单里有「导入工作项」，见 [导入工作项](#导入工作项) |
| 搜索 | 按名称或编号搜索工作项 |
| 处理人 | 按项目成员筛选 |
| 筛选 | 按截止日期范围、最后更新时间、计时状态和累计时长等条件筛选 |
| 排序 | 按多列排序，可以随时「清除」 |
| 隐藏 | 选择要显示的列 |
| 分组 | 「按字段分组」：状态、优先级、工作项类别或时长追踪列 |
| 隐没已完成 | 淡化本人定义为已完成的工作项 |
| ◷ 小计时器 | 打开悬浮的小计时器（计时器关闭时不显示） |

::: info 这些设置只影响你自己
筛选、排序、隐藏的列、分组、行高、固定列和条件着色都是你个人的表格设置，不会改变同事看到的表格。
:::

## 隐没已完成

打开「隐没已完成」后，已完成的工作项会淡化显示但仍保留在原位，方便你专注于未完成的事。哪些状态算“已完成”可以在同一个菜单里按项目自己定义（「本项目中视为已完成的状态（仅自己）」）。

## 快速添加

在表格底部的「添加工作项」输入名称：

- `Enter` 创建；
- `Shift+Enter` 创建后留在输入框里继续添加下一条。

表格按字段分组时，每组底部都有「添加工作项」，新工作项会落在该组里。你还可以在「表格设置 → 新建默认值」里设置新工作项的默认状态、处理人等字段。

## 批量操作

勾选多行后，表格底部出现批量操作栏：

| 操作 | 说明 |
|---|---|
| 编辑已选行 | 编辑任意一个已选单元格，可同步修改所有已选行 |
| 复制 | 复制所选工作项 |
| 移动 ▾ | 「置顶」「置底」调整手动顺序（需要先清除排序） |
| 转为子工作项 | 把所选工作项挂到另一个工作项下 |
| 归档、删除 | 归档后从列表隐藏，可以通过工作项链接恢复 |

## 导入工作项

可以把 Excel 或 CSV 里的工作项一次导入到当前项目，常用于从其他协作平台迁入。点击「新增工作项」右侧的 ▾ →「导入工作项」，仅在表格视图且你能添加工作项时可用。

导入分三步：

1. **上传文件**：拖入或选择 `.csv`、`.xlsx`、`.xls` 文件，最大 5 MB、2000 行；第一行非空行作为表头。
2. **映射列与取值**：「标题」必须映射到一列，其余列可以选择导入为类别、状态、优先级、处理人、截止日期、父工作项、备注，或「不导入」，每个字段只能用一列。表头名称与字段相同或相近时会自动映射。
   - 状态、优先级、类别和处理人要把文件里的每个值对应到项目里的值：名称或编码相同的会自动匹配；匹配不到的，状态默认「未开始」，优先级留空，类别使用「导入为类别」，处理人不分配。
   - 处理人可以用 `;`、`,`、顿号或空格分隔多人，只在项目的有效成员里匹配；同名的多位成员需要你手动选择。
   - 无法识别的截止日期会留空，界面会提示行数。
3. **处理重复并预览**：选择遇到同名工作项时怎么办，预览会列出新增、更新、跳过和无法导入的行数，展开问题列表可以看到每一行的原因，确认后点「导入 N 项」。

重复只按**标题**匹配（项目里未删除、未归档的工作项，忽略标题两端空白）：

| 方式 | 效果 |
|---|---|
| 全部新增 | 即使已有同名工作项，也全部导入 |
| 跳过已有 | 标题与项目中已有工作项相同的行不导入 |
| 更新已有 | 覆盖同名工作项里**已映射的字段**，已映射列的空单元格会清空对应字段；没有同名项的行新增 |

::: warning 更新模式会清空字段
选择「更新已有」时，已映射的列里为空的单元格会把原有的值清掉。只想改部分字段时，把其他列设为「不导入」。
:::

导入的规则：

- 新增的工作项按文件顺序排在表格最前，状态直接取文件里映射的状态，不必从「未开始」逐步推进。
- 「父工作项」列填父项的标题：先在文件里找，再在项目已有工作项里找。工作项只有两级，父项本身是子项时，会挂到它的最上层父项下；找不到或有多个同名父项时，该行作为顶层工作项导入并在问题列表里提示。
- 状态为已完成的工作项，完成时间是导入的时刻，不是原平台的完成时间。
- 导入不会产生项目动态，也不会给处理人发通知。
- 不导入工时：「完成工时」之类的列不能映射。历史工时请在 团队视图 → 成员工时 → 「迁入工时」中另行迁入。
- 个别行有问题不影响其他行：无法导入的行会被跳过，其余行照常导入。

## 子项与连接列

- **子项**：工作项可以有一级子工作项。点击名称左侧的展开按钮查看；行菜单里可以「转为独立工作项」。
- **连接列**：点击表头最右侧的「+」添加跨项目连接列，把本项目工作项与其他项目的工作项关联。连接是双向的，两个项目的表格里都能看到对方。

## 列头菜单

点击列头可以升序、降序或清除排序，状态、优先级、工作项类别和时长追踪列还可以直接作为「分组依据」。时长追踪列的列头菜单里也能开关「使用计时器」。

分组显示时，保存按各组内的排序结果分别生效。

## 看板

看板按状态分列，拖动卡片即可推进状态。看板不支持分组和隐没已完成。

## 常见问题

::: details 为什么我不能拖动调整顺序？
表格正在按某列排序时，手动顺序不可用。先在「排序」里清除排序。
:::

::: details 为什么快速添加按钮是灰的？
项目已归档、项目没有可用的工作项类别，或你不是项目成员时，不能添加工作项。
:::

::: details 为什么我新增的状态在首页只出现在「全部」？
首页「我的工作项」的「待开始」只统计项目初始状态「未开始」，「进行中」统计进行中、卡住这类状态；团队自己新增的状态（如「测试中」）只列在「全部」，首页项目卡片把它们计为「其他」。哪些状态算“已完成”，可以在表格「隐没已完成」菜单里按项目自己定义。
:::

::: details 导入时提示「项目中有多个同名工作项」是怎么回事？
「更新已有」按标题找要更新的工作项，项目里有多个同名项时无法确定更新哪一个，这一行不会导入。可以先给重复的工作项改名，或改用「跳过已有」「全部新增」。
:::

::: details 文件里同一个标题出现多行，更新时为什么都无法导入？
同一标题在文件里出现多次，并且项目里已有同名工作项时，无法判断每一行对应哪个已有项，这些行都会被跳过。请先把文件里的标题改成不重复。
:::

::: details 找不到「导入工作项」？
它在「新增工作项」右侧的 ▾ 菜单里，只在表格视图出现；项目已归档、没有可用的工作项类别或你不是项目成员时看不到。
:::
