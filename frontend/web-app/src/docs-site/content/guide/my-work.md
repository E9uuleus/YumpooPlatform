「我的工作」把分配给你、还没完成的工作项按项目汇总在一页，适合每天开工时快速处理手头的事。

## 入口

左侧模块栏「我的工作」。这个页面没有二级导航。

## 显示哪些工作项

- 处理人包含你的工作项，包括子工作项；
- 是否“完成”沿用你在各项目表格「隐藏已完成」旁设置的完成状态，未设置时「已完成」「已取消」两类算完成；
- 只包含你能编辑的进行中项目，已归档或已结束的项目不显示；已归档、已删除的工作项不显示。

项目标题后的数字是该项目中分配给你、未完成的工作项数。只因为其下有你的子项而显示的父项会标注「父项上下文」，并自动展开显示你的子项。

在另一个窗口修改项目的完成状态设置后，点页头的刷新按钮。项目计数和已展开的表格会按新设置重新加载。

## 在表格中编辑

每个项目下是与项目页相同的工作项表格：可以改名，修改处理人、状态、优先级、类别、截止日期，计时和打开讨论。改成已完成的工作项会先变淡，刷新后移出。点击项目标题可以折叠，折叠状态保存在当前设备；「打开项目」进入项目的工作项表格。

## 新建工作项

点击项目表格底部的「新建工作项」打开新建窗口：填写名称，设置处理人（默认是你）、状态、优先级、类别和截止日期后创建。在行菜单中选择「添加子项」会新建到该工作项下。

## 工作项详情

点击名称旁的详情按钮打开工作项。左侧可以修改名称和字段，点击「最后更新时间」可查看动态。右侧提供「详情」「协作讨论」「动态」，用法见 [协作讨论](collaboration.md)。点击所属项目名进入项目并定位到这个工作项。窗口较窄时字段排在上方、标签页排在下方。

## 常见问题

::: details 为什么某个分配给我的工作项没有出现？
它可能已按你的完成设置算作完成、已归档，或所在项目已结束、已归档，或者你已不是该项目的在职成员。
:::
