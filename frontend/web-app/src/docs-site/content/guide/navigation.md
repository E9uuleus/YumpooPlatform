应用界面由三部分组成：最左侧的**模块栏**、模块栏旁边的**二级导航**，以及页面顶部的**顶栏**。

## 入口

| 区域 | 位置 | 作用 |
|---|---|---|
| 模块栏 | 最左侧一列图标 | 在「首页」「工作台」之间切换；管理员还会看到「团队」「公司管理」「运维」 |
| 二级导航 | 模块栏右侧 | 当前模块里的页面，例如工作台下的「仪表板」「我的工时」「管理项目」「归档项目」和你参与的项目 |
| 顶栏 | 页面顶部右侧 | 查看本页引导、帮助、收件箱、偏好设置和个人菜单 |

## 模块栏与二级导航

模块栏随你的角色变化，见 [角色与权限](../intro/roles.md)。进入一个项目后，二级导航会显示「当前项目」下的「工作项」「统计」「成员」「动态」「设置」。工作台菜单「项目」一行右侧的 + 可以直接创建项目。

窗口宽度小于 1280px 时，二级导航默认收起，给内容留出空间。点击模块栏顶部的展开按钮即可打开；页面导览遇到收起的导航时，也会指向这个按钮。

仪表板、我的工时、团队、公司管理、运维中心和偏好设置页向下滚动时，只有内容区滚动，模块栏、二级导航和页面标题保持不动。这些页面顶部统一显示模块图标、模块名和当前页面的标题。

## 页面加载提示

打开或切换页面时，顶部细条表示页面和主要内容仍在加载，完成后自动消失。它不代表精确百分比；快速加载时可能不会出现。首次启动仍显示品牌启动画面，表格、列表和按钮保留各自的加载提示。后台自动刷新不会反复显示顶部细条。浏览器与桌面客户端主窗口的行为一致。

## 首页

首页是登录后的第一屏，从上到下是问候栏、快捷入口，以及左右两栏。

- **问候栏**：显示日期和问候语，下方的标签汇总计时中的工作项、进行中数量、逾期数量和未读通知数。
- **快捷入口**：「管理项目」「收件箱」和计时入口人人可见；第二张卡片对公司管理员是「团队视图」，其他成员是「仪表板」；公司管理员多一张「公司管理」，平台管理员多一张「运维」。计时器开启时计时入口是「开始计时」（计时中显示已用时长），关闭时是「记录工时」，直接打开今天的时间线。
- **我的工作项**：分配给你、还没完成的工作项，进行中的排在前面，点击打开所在项目里的工作项。截止日期过了的标红并写明“逾期”。顶部可以切换：
  - 「全部」：所有这些工作项；
  - 「进行中」：状态属于进行中的工作项；
  - 「待开始」：只统计项目初始状态「未开始」。团队自己新增的状态（如「测试中」）只计入「全部」，不计入「待开始」。
- **我的项目**：你参与的进行中项目，最多显示 6 个，逾期和未完成多的项目排在前面；点击项目名进入工作项表格，「全部项目」进入「管理项目」。卡片上的数字是分配给你的工作项：进行中、待开始、其他、逾期，团队自定义状态计为「其他」。
- **工时日历**：本月每天记录的工时和月合计，有记录的日期着色，达到当天标准工时的颜色最深，今天带边框，悬停可看当天时长；「查看明细」进入 [我的工时](time-tracking.md#我的工时)。计时中的时长会实时计入今天。

## 顶栏

| 按钮 | 作用 |
|---|---|
| 查看本页引导 | 重新播放当前页面的界面导览；当前页面没有导览时按钮显示为灰色 |
| 帮助 | 打开「本页帮助」「快速开始」「帮助中心」和「常见问题」；在浏览器中新开标签页，在桌面客户端中直接在当前窗口打开 |
| 收件箱 | 显示未读通知数，点击打开收件箱 |
| 偏好设置 | 打开偏好设置页 |
| 个人菜单 | 点击头像：查看版本、「下载桌面客户端」（仅浏览器中显示）、「退出并重新认证」 |

## 偏好设置

偏好设置页集中了个人偏好：

- **外观**：主题可选「跟随系统」「浅色」「深色」「夜间」，密度可选「舒适」「紧凑」。外观只保存在当前设备上，浏览器和桌面客户端分别设置。
- **窗口**与**常规**（仅桌面客户端）：悬浮计时的显示方式、项目侧边栏、全局快捷键、登录时启动、自动下载更新等，见 [桌面客户端](desktop.md)。

计时器开关和上班时间在「我的工时」右上角的计时偏好里设置，见 [计时偏好](time-tracking.md#计时偏好)。

## 在手机上使用

窄屏下模块栏和二级导航收进左上角的菜单抽屉，顶栏只保留图标按钮。表格类页面可以左右滑动查看更多列。

## 常见问题

::: details 引导不见了怎么重看？
点击右上角的「查看本页引导」按钮。首页、工作台、项目工作项、仪表板、我的工时、我的一天、收件箱、团队视图和公司管理等页面都有导览。
:::

::: details 为什么看不到「团队」或「公司管理」？
这两个模块只对公司管理员显示。需要时请联系平台管理员。
:::
