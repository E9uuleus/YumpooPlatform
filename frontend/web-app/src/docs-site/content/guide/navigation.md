应用界面由三部分组成：最左侧的**模块栏**、模块栏旁边的**二级导航**，以及页面顶部的**顶栏**。

## 入口

| 区域 | 位置 | 作用 |
|---|---|---|
| 模块栏 | 最左侧一列图标 | 在「首页」「工作台」之间切换；管理员还会看到「团队」「公司管理」「运维」 |
| 二级导航 | 模块栏右侧 | 当前模块里的页面，例如工作台下的「仪表板」「我的工时」「管理项目」「归档项目」和你参与的项目 |
| 顶栏 | 页面顶部右侧 | 查看本页引导、帮助、收件箱、偏好设置和个人菜单 |

## 模块栏与二级导航

模块栏随你的角色变化，见 [角色与权限](../intro/roles.md)。进入一个项目后，二级导航会显示「当前项目」下的「工作项」「统计」「成员」「动态」「设置」。

窗口宽度小于 1280px 时，二级导航默认收起，给内容留出空间。点击模块栏顶部的展开按钮即可打开；页面导览遇到收起的导航时，也会指向这个按钮。

仪表板、我的工时、团队、公司管理、运维中心和偏好设置页向下滚动时，只有内容区滚动，模块栏、二级导航和页面标题保持不动。这些页面顶部统一显示模块图标、模块名和当前页面的标题。

## 顶栏

| 按钮 | 作用 |
|---|---|
| 查看本页引导 | 重新播放当前页面的界面导览；当前页面没有导览时按钮显示为灰色 |
| 帮助 | 打开「本页帮助」「快速开始」「帮助中心」和「常见问题」；在浏览器中新开标签页，在桌面客户端中直接在当前窗口打开 |
| 收件箱 | 显示未读通知数，点击打开收件箱 |
| 偏好设置 | 打开偏好设置页 |
| 个人菜单 | 点击头像：查看版本、「下载桌面客户端」（仅浏览器中显示）、「退出并重新认证」 |

## 偏好设置

偏好设置页集中了个人偏好：

- **外观**：主题可选「跟随系统」「浅色」「深色」「夜间」，密度可选「舒适」「紧凑」。外观只保存在当前设备上，浏览器和桌面客户端分别设置。
- **窗口**与**常规**（仅桌面客户端）：悬浮计时的显示方式、项目侧边栏、全局快捷键、登录时启动、自动下载更新等，见 [桌面客户端](desktop.md)。

计时器开关和上班时间在「我的工时」右上角的计时偏好里设置，见 [计时偏好](time-tracking.md#计时偏好)。

## 在手机上使用

窄屏下模块栏和二级导航收进左上角的菜单抽屉，顶栏只保留图标按钮。表格类页面可以左右滑动查看更多列。

## 常见问题

::: details 引导不见了怎么重看？
点击右上角的「查看本页引导」按钮。首页、工作台、项目工作项、仪表板、我的工时、我的一天、收件箱、团队视图和公司管理等页面都有导览。
:::

::: details 为什么看不到「团队」或「公司管理」？
这两个模块只对公司管理员显示。需要时请联系平台管理员。
:::
