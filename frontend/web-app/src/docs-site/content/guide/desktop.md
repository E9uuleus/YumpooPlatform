Yumpoo Desktop 是 Windows 客户端，界面和数据与浏览器里完全一样，另外提供常驻桌面的计时、托盘快捷操作和系统提醒。安装方法见 [安装桌面客户端](../start/desktop.md)。

::: info 版本说明
本页以桌面客户端 1.1.2 为准。看不到小窗固定、缩放等入口时，请先更新客户端。
:::

## 悬浮计时

计时器开启时，桌面上会显示计时：

- **悬浮球**：小圆球显示当前计时，点击展开计时面板；
- **项目侧边栏**：收在屏幕边缘的窄长栏，显示常用项目。鼠标推到边缘即可滑出，点击项目图标直接填报工时，拖动可以移动或换边；开启「顶部显示计时」后，侧边栏顶部显示当前计时，取代悬浮球。

显示方式、屏幕边缘、大小和显示层级（「浮在其他应用上方」或「普通窗口」）在「偏好设置 → 窗口」里设置。

## 托盘

任务栏右侧的托盘图标：

- **左键**或自己录制的全局快捷键：打开快捷工时小窗；
- **右键**：计时快捷菜单，包括「打开主界面」「查找工作项…」「暂停并保存计时」「检查更新」「偏好设置…」「诊断与修复…」和退出。托盘菜单里也能看到更新状态。

## 快捷工时小窗

不打开主窗口就能补录工时：

::: steps
1. 在顶部搜索工作项（搜索包含已完成的工作项），或点项目标签按项目筛选。候选按项目分组，列出分配给你或你最近记录过的工作项。
2. 点击一个工作项展开：选择「今天」「昨天」，或用箭头逐日回到更早的日期。
3. 选择时长（15 分钟、30 分钟、1 小时、2 小时或自定义），小窗会提示将排入当天上班后的哪个空档。
4. 点「记录」完成；计时器开启时也可以直接「开始计时」。
:::

- 点图钉可以**固定**小窗：固定后小窗不会因失去焦点而隐藏，会出现在任务栏，可以拖动标题栏移动、从右下角缩放；重启后保留位置与大小。
- 底部「隐藏已完成」开关和「我的一天」入口，后者在主窗口打开当天的时间线。

## 收件箱提醒

收到新通知时，客户端在任务栏显示未读角标，并弹出系统提醒；点击提醒打开对应工作项。

## 偏好设置

在主窗口打开「偏好设置」，桌面客户端比浏览器多出两组：

| 分组 | 设置项 |
|---|---|
| 窗口 | 显示方式、项目侧边栏、顶部显示计时、屏幕边缘、大小、显示层级、保持在任务栏上方（实验性）、快捷键 |
| 常规 | 登录时启动、自动下载更新、检查更新 |

## 自动更新

- 客户端在后台检查和下载新版本，核对公司签发的签名、版本、文件大小和摘要后，在你**退出时安装**；也可以点「重启以更新」立即完成。
- 只接受比当前更高的版本，不会降级；任何一项核对不通过都不会安装。
- 关闭「自动下载更新」后，检查到新版本时由你手动下载。

## 诊断与修复

托盘菜单「诊断与修复…」检查网络、证书和服务健康状况，可以重置本机偏好或导出诊断包（诊断包可能含内存片段，只发给管理员）。连续启动失败时，客户端会自动进入**安全模式**：关闭硬件加速，先打开诊断窗。开始菜单里也有「Yumpoo Desktop (Safe Mode)」快捷方式。

## 常见问题

::: details 关闭主窗口会停止计时吗？
不会。计时持续到你主动暂停；关闭主窗口或隐藏浮窗都不会暂停。
:::
