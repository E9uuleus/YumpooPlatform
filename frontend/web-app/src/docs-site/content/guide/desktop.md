Yumpoo Desktop 是 Windows 客户端，界面和数据与浏览器里完全一样，另外提供常驻桌面的计时、托盘快捷操作和系统提醒。安装方法见 [安装桌面客户端](../start/desktop.md)。

::: info 版本说明
本页以桌面客户端 1.1.4 为准。项目简称保存和侧边栏自动收起隐藏项目空位需要此版本；看不到相应效果时，请先检查更新。
:::

## 悬浮计时

计时器开启时，桌面上会显示计时：

- **悬浮球**：小圆球显示当前计时，点击展开计时面板；
- **项目侧边栏**：收在屏幕边缘的窄长栏，显示常用项目。自动隐藏时只在边缘留一枚小把手，计时中把手会亮起；鼠标推到边缘即可滑出，点击项目图标直接填报工时，拖动可以移动或换边；开启「顶部显示计时」后，侧边栏顶部显示当前计时，取代悬浮球。首字相同不好区分时，可以在偏好设置的「窗口 → 项目」里给项目填 1–3 字简称，侧边栏改为显示简称。

显示方式、屏幕边缘、大小和显示层级（「浮在其他应用上方」或「普通窗口」）在「偏好设置 → 窗口」里设置。

已结束或归档的项目会暂时从项目侧边栏隐藏，固定配置和简称会保留。项目重新打开或恢复后，再次聚焦侧边栏即可重新显示；拖动其他项目不会改变隐藏项目的位置。聚焦刷新期间保留上次显示结果；首次读取尚未完成或失败时显示原有固定项目。支持可见数量同步的桌面版本会同时收起隐藏项目的空位，旧版仍按保存的数量排版。

## 托盘

任务栏右侧的托盘图标：

- **左键**或自己录制的全局快捷键：打开快捷工时小窗；
- **右键**：计时快捷菜单，包括「打开主界面」「查找工作项…」「暂停并保存计时」「检查更新」「偏好设置…」「诊断与修复…」和退出。托盘菜单里也能看到更新状态。

托盘右键菜单随客户端安装，启动中和断网时仍使用同一界面，并保留诊断、更新与退出入口；主题使用上次同步的设置，首次启动跟随系统。此行为需要升级到包含本地菜单的客户端，旧版仍可能显示系统备用菜单。

## 退出客户端

关闭主窗口只会收起到托盘。要完全退出，请在托盘右键菜单选择「退出」。存在运行计时时，可以选择「停止全部并退出」「继续计时并退出」或取消。

启动尚未完成，或检查、保存计时超过 30 秒时，客户端会提供「取消退出」和「继续计时并退出」。后者不会自动停止计时，也不代表之前的保存已成功；重新打开后可核对结果。等待你选择时不会自动超时退出。

## 快捷工时小窗

不打开主窗口就能补录工时：

::: steps
1. 在顶部搜索工作项或分类（搜索包含已完成的工作项），或点项目标签按项目筛选；项目较多时用鼠标滚轮左右滚动标签栏，边缘渐隐表示那一侧还有项目。候选按项目分组，列出分配给你或你最近记录过的工作项；最上方一行是通用工时「出差」「学习」「商务」「会议」，选中某个项目时，分类记录会关联到该项目。
2. 点击一个工作项展开：选择「今天」「昨天」，或用箭头逐日回到更早的日期。
3. 选择时长（15 分钟、30 分钟、1 小时、2 小时或自定义），小窗会提示将排入当天上班后的哪个空档；需要指定起止时间时，点「改时段」。
4. 点「记录」完成；计时器开启时也可以直接「开始计时」。
:::

- 点图钉可以**固定**小窗：固定后小窗不会因失去焦点而隐藏，会出现在任务栏，可以拖动标题栏移动、从右下角缩放；重启后保留位置与大小。
- 工作项标题过长被截断时，鼠标停留片刻会显示完整标题。
- 底部「隐藏已完成」开关和「我的一天」入口，后者在主窗口打开当天的时间线。
- 子工作项缩进显示在父工作项下方并用连接线相连；父工作项不在列表中时，显示一行灰色的父项标题。

### 手动改时段

点「改时段」后，在原提示行填写开始和结束时间；可以输入 `9`、`930` 或 `9:30`，用 ↑ / ↓ 每次调整 15 分钟，按 Enter 记录。选择时长会同时调整结束时间。

- 时段至少 15 分钟，结束必须晚于开始，不能早于当天或晚于当前时间。
- 与已有记录重叠的部分会跳过；整段都已记录时不能再次记录。
- 点「自动」恢复按时长排入空档。重新打开小窗、展开另一工作项或新建后展开工作项，都会回到自动模式；手动模式下切换日期会保留钟点。

### 修改状态与新建工作项

- 工作项左下角直接显示项目实际的状态名称和颜色，与表格一致。点击状态菜单选择目标状态；需要说明时填写后确认。没有修改权限时只读。
- 点击工作项右侧的「时钟加号」可展开工时填报区。
- 点击搜索框右侧的「文档加号」新建工作项；搜索没有结果时也可点「新建」并沿用搜索文字。选择项目、输入标题后按 Enter 创建；中文输入法确认候选字不会提交，Esc 关闭。
- 新工作项默认分配给你，使用所选项目第一个启用的类别，不套用个人表格的新建默认值。创建后自动展开记录区，方便继续补录工时。
- 修改状态或创建成功后，主窗口中对应项目的表格或看板、首页「我的工作项」会同步刷新。

## 收件箱提醒

收到新通知时，客户端在任务栏显示未读角标，并弹出系统提醒；点击提醒打开对应工作项。

## 偏好设置

在主窗口打开「偏好设置」，桌面客户端比浏览器多出两组：

| 分组 | 设置项 |
|---|---|
| 窗口 | 显示方式、项目侧边栏、顶部显示计时、屏幕边缘、大小、显示层级、保持在任务栏上方（实验性）、快捷键 |
| 常规 | 登录时启动、自动下载更新、检查更新 |

## 自动更新

- 客户端在后台检查和下载新版本，核对公司签发的签名、版本、文件大小和摘要后，在你**退出时安装**；也可以点「重启以更新」立即完成。
- 只接受比当前更高的版本，不会降级；任何一项核对不通过都不会安装。
- 关闭「自动下载更新」后，检查到新版本时由你手动下载。

## 诊断与修复

托盘菜单「诊断与修复…」检查网络、证书和服务健康状况，可以重置本机偏好或导出诊断包（诊断包可能含内存片段，只发给管理员）。连续启动失败时，客户端会自动进入**安全模式**：关闭硬件加速，先打开诊断窗。开始菜单里也有「Yumpoo Desktop (Safe Mode)」快捷方式。

## 常见问题

::: details 关闭主窗口会停止计时吗？
不会。计时持续到你主动暂停；关闭主窗口或隐藏浮窗都不会暂停。
:::
