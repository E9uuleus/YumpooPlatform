每个工作项都有详情面板，描述、讨论、附件和动态都集中在这里。

## 入口

在表格中点击工作项名称旁的讨论图标，或在看板中点击卡片，打开工作项详情。收件箱里的通知也会直接打开对应工作项的详情。

## 描述

描述是富文本：支持标题、列表、任务清单、表格、链接、文字颜色与字号，可以直接粘贴或拖入图片。单张内联图片不能超过 20 MiB。

## 讨论

| 操作 | 说明 |
|---|---|
| 发表讨论 | 在「协作讨论」标签的编辑器里输入，支持与描述相同的富文本 |
| 回复 | 讨论支持两级：讨论下可以回复，回复不再嵌套 |
| @提及 | 输入 `@` 选择项目成员，对方的收件箱会收到「在…中提到了你」 |
| 置顶 | 把重要讨论置顶，固定显示在最上方 |
| 编辑与删除 | 你可以编辑或删除自己的讨论 |

## 附件

可以在讨论里粘贴或拖入文件，作为附件上传。

- 单个文件不超过 **100 MiB**。
- 只接受常见的文档、图片和压缩包类型；扩展名与文件内容不一致时会被拒绝（提示「文件类型不允许」）。
- 含宏的 Office 文档会被拒绝。
- 下载附件时总是作为文件下载，不会在浏览器里直接打开。

## 动态与历史

- 工作项详情有「详情」「协作讨论」「动态」三个标签。「动态」按时间列出这个工作项的修改记录：谁在什么时候把哪个字段从什么改成了什么。
- 项目整体的变化（工作项创建、讨论、成员变动等）在项目的「动态」页查看，见 [项目](projects.md#动态)。

## 常见问题

::: details 附件上传失败怎么办？
常见原因是文件超过 100 MiB、类型不在允许范围内，或 Office 文档里含有宏。换成允许的格式（例如另存为不含宏的文档或打包成 zip）后重试。仍然失败时，把提示文字发给管理员。
:::
