仪表板是你自己的统计看板，只有你能看到。每个仪表板由若干组件组成，可以连接多个项目一起统计。

## 入口

模块栏「工作台」→ 二级导航「仪表板」。顶部的标签在你的多个仪表板之间切换。

## 新建与管理仪表板

- 点标签栏的「+」新建仪表板，起始内容可以选「空白仪表板」或「项目概览」。
- 右上角「仪表板更多操作」里可以「重命名」「复制仪表板」「恢复默认布局」或「删除仪表板」。恢复默认布局会换回默认的 8 个组件及其布局。

## 添加组件

点击「添加组件」选择组件类型：

| 组件 | 内容 |
|---|---|
| 指标卡 | 一个关键数字，例如进行中或逾期的工作项数 |
| 状态分布 | 工作项按状态的分布 |
| 项目工作量、成员工作量 | 按项目或成员统计工作项数量 |
| 项目耗时 | 各项目记录的工时 |
| 自定义图表 | 自选维度与度量，支持柱形图、条形图、折线图、面积图、饼图、环图和气泡图 |
| 工作项表格 | 符合筛选条件的工作项列表 |

每个仪表板最多 40 个组件。组件菜单里可以全屏查看或修改设置。

## 连接项目与筛选

- 「连接项目」选择这个仪表板统计哪些项目。
- 「筛选」按处理人、状态、状态分类、优先级、工作项类型等条件过滤所有组件，可以选择是否包含已归档工作项。

## 布局

拖动组件调整位置和大小，修改会**自动保存**。另一个窗口同时修改了同一个仪表板时，会提示你选择「重新载入」或继续编辑。

## 刷新与导出

右上角「刷新仪表板」重新读取数据，「导出 PDF」把当前仪表板导出为 PDF 文件。
