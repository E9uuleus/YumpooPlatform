收件箱汇总和你有关的通知。顶栏的收件箱按钮显示未读数，点击进入收件箱。

## 入口

顶栏右上角的收件箱按钮。

## 通知分类

| 分类 | 内容 |
|---|---|
| 未读 | 还没读过的通知 |
| 全部 | 所有未归档的通知 |
| @我 | 有人在讨论或描述里提到你 |
| 评论与回复 | 你关注的工作项有新评论，或有人回复了你 |
| 指派给我 | 有人把工作项指派给你 |
| 项目动态 | 成员加入或移出、负责人变更、项目删除计划等 |
| 已归档 | 你归档过的通知 |

## 通知类型

- **@提及**：「在 … 中提到了你」
- **回复与评论**：「回复了你在 … 的评论」「评论了 …」
- **指派**：「将 … 指派给你」
- **连接**：有人「向你负责的项目新建了」连接的工作项
- **成员变动**：把你或其他成员加入、移出项目，负责人转交
- **项目删除**：删除计划、到期前提醒、撤销删除
- **工时提醒**（公司管理员）：成员单日工时超过阈值

## 处理通知

- 点击通知直接打开相关工作项；讨论类通知会打开详情里的讨论。
- 每条通知可以「标为已读」「标为未读」或归档。
- 右上角「全部标为已读」清空当前分类的未读。

## 项目通知偏好

在项目页右上角的项目菜单（⋯）中点「通知提醒」，可以按项目设置（菜单里会显示当前设置）：

| 选项 | 效果 |
|---|---|
| 接收全部 | 接收此项目中与你相关的全部通知 |
| 自定义 | 只接收你选择的通知类型 |
| 全部静音 | 不再接收此项目的通知 |

## 桌面端提醒

桌面客户端会在任务栏显示未读角标，并在收到新通知时弹出系统提醒；提醒方式在桌面客户端里设置。
